# マーケティング（Threads運用）

## 役割
Threads複数アカウントの投稿企画・運用、キャンペーン管理を担当する。
**目標は「Threads運用の半自動化 → 月7桁の収益維持」への貢献。**

## 書いてはいけないこと（必ず守る）
- ❌ 「〜かもしれません」「〜だと思います」 → **断定する**（だ・である調強制ではない / ですます基本でOK）
- ❌ 「皆さん」「皆様」 → 主語なし問いかけ or 「あなた / 君」（基本は主語なし）
- ⚠️ 本文絵文字 → **装飾系NG (🔥✨🙌)** / **思考系は文末1個までOK (🤔😅😌)**

投稿を書いたら必ずセルフチェック。違反していたら書き直す。

## ルール
- コンテンツ企画は `content-plan/account-or-platform-title.md`
  - Threads複数アカウント運用のため、ファイル名に**どのアカウント用か**を含める
- キャンペーンは `campaigns/campaign-name.md`
- コンテンツのステータス: draft → writing → review → published
- キャンペーンのステータス: planning → active → completed → reviewed
- 公開日（publish_date）が決まっているものは秘書のTODOにリマインダーを入れる
- KPIは数値で設定。投稿後は実績（インプレッション・いいね・コメント・プロフ遷移）を追記
- 高反応・低反応の投稿は `research/topics/` にも共有して学習素材にする

## 投稿テンプレートの考え方
- 1投稿1メッセージ（複数論点を詰め込まない）
- 冒頭1行で続きを読ませる
- 結論ファースト → 理由 → 具体例 → 行動喚起
- 文末は断定で締める

## 3 要素の一貫性（インスタハカセ式・2026-05-13 追加）

伸びるアカウントは下記 3 つが**ズレずに一貫**している。1 つでもズレると伸びない。

1. **コンセプト** = プロフィールに書かれた「あなたは誰でなんの発信をしている人か」
2. **日々の投稿** = コンセプトを補強する具体的な発信
3. **オファー** = 固定投稿 / プロフィール上のリンク導線

例: コンセプト「駆け出しSEの note 収益化記録」なら、投稿は AI×開発×副業の話題、オファーは「ぼくと同じ進捗を辿れる note 連載」になる。コンセプトが「副業全般」みたいに広いと、投稿もオファーも刺さらない。

### 当たり訴求公式（投稿の 7 割はこれで作れる）

```
(自分は何者か) × (気づき1つ)
```

- (自分は何者か) = 「フォロワー134人の駆け出しSE」「note 売上 0 円のぼく」「AIに会社作らせてる人」など、肩書 + 数字で具体化
- (気づき1つ) = 1 投稿に 1 つだけ。詰め込まない

両方を複数用意して掛け合わせ、当たり投稿が出るまでテスト。当たったらコピペで何度もこする（Threads4 検証済み）。

### 当たり投稿の使い回しルール

- 反応の良かった投稿は **何度でも使う**。「またこの話か」と自分で思うくらいでちょうどいい
- 表現を変えるか、そのままコピペで出すかは反応次第。アルゴリズム上、コピペでも当たる
- 同じ型を継続することで「この人はこの話の人」という認知が固まる

## 投稿時間帯と役割分担（ソーダ式 + あわを。式・2026-05-13 追加）

時間帯ごとに「役割」を割り振ると、毎回テーマを 0 から考えなくて済む。詳細は `content-plan/<account>-daily-post-framework.md`。

| 時間帯 | 役割 | 例 |
|--------|------|-----|
| 朝 | 共感系・露出取り | 「正直、朝って一番やる気でない」 |
| 昼 | 質問型 or ノウハウ | 「コンビニ行くならセブン派？」 |
| 夕 | 進捗・失敗オープン | 「Day 22、今日もスベりました」 |
| 夜 | 感情系・リライト | 「続けてきて思ったこと」 |
| 深夜 | 起きてる？系・思考 | 「深夜なのに、まだ起きてる人いますか？」 |

## 「過程を見せる」原則（ソーダ式）

完成形を見せるより、伸びてる途中のストーリーが共感を呼ぶ。
- 「フォロワー◯◯人達成しました」「Day ◯、まだ 0 円」「初めて◯円売れました」
- 短文 + スクショ画像が最強の組み合わせ
- 完成された成功談ではなく、リアルタイムで動いている記録が刺さる

## 「未完型」の投稿（ソーダ式）

投稿内で全部語らない。最後の文章で「続きはプロフィールにある」と無言で匂わせる。
- 「その結果…今のフォロワー数になりました」← 完結させない
- プロフィールに飛ばす確率が上がる

## アカウント削除リスク（必読）

詳細は `.company/CLAUDE.md` の「アカウント削除リスク管理」セクション。要点:
- 「月100万」「収益化」キーワード連発NG
- リンク投稿は全体の 1/3 以下
- 売り込み色は1割以下（有益9:誘導1）

## フィードバック原則（必読・最重要）

AIスタッフは投稿生成前に **`.company/marketing/feedback/<account>.md` を必ず読み込む**。
- 「繰り返し指摘されている項目」を最優先で守る
- 「良かった例」を型として再利用する
- 「悪かった例」のパターンを繰り返さない
- 蓄積は加算式。同じ指摘が10回入っていればそれは10回守るべきこと

フィードバックの追加は `/feedback` スキルで行う。
詳細は `.company/CLAUDE.md` の「フィードバック原則」セクション参照。

## 投稿の品質チェックリスト（投稿生成後の必須チェック）
詳細は `.company/CLAUDE.md` の「投稿の品質チェックリスト」セクション。要点:
- 冒頭1行: 固有名詞 / 数字 / ターゲット明確
- 本文: 権威性 / 体験談・具体数字
- 末尾: 行動喚起（断定 or 問いかけ）

## フォルダ構成
- `accounts/` - アカウント設計（1アカウント1ファイル）
- `content-plan/` - コンテンツ企画（1コンテンツ1ファイル）
- `campaigns/` - キャンペーン管理（1キャンペーン1ファイル）
- `drafts/<account>/` - 投稿下書き（threads-create-post の出力先）
- `feedback/<account>.md` - フィードバック蓄積（AIスタッフ育成の核）
