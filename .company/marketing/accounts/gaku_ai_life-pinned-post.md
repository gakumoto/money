# gaku_ai_life 固定投稿（LP）設計

## なぜ固定投稿が重要か（インスタハカセ式・Threads4 より）

> 「固定投稿は LP みたいなもの」by インスタハカセ

タイムラインで興味を持った人がプロフィールに来て、最初に読むのが固定投稿。
ここで「フォローする理由」と「複数のオファー入口」を提示する。

インスタハカセは固定投稿経由で **LINE 登録 2,000 件以上**を獲得した。

## 設計原則

### 1. 投稿当たり訴求とオファーの一貫性

> 「当たりの訴求が出た時点で、その訴求に合わせてオファーを変える」by インスタハカセ

例:
- 投稿で「AI に下書き 10 本作らせる方が早い」が当たる
  → 固定投稿で「AI に会社作らせる全手順を note 連載してます」
- 投稿で「119 字に削った投稿の編集記録」が当たる
  → 固定投稿で「フィードバック蓄積の全プロセスを公開してます」

訴求がズレるとオファーも刺さらない。

### 2. 複数のオファー入口を埋め込む

固定投稿に**キャッチーな実績や数字を 4〜5 個羅列**しておく。これで日々の投稿で
「○○○の方法は固定投稿に書いてます」と自然な誘導がしやすくなる。

インスタハカセの実例:
```
▶切り抜きのリールを週1投稿で月100万
▶ストーリーでぺら1枚投稿して300万
▶リール1本で3000万
▶テキストだけのシンプルフィード1投稿でフォロワー6000人増加
```

gaku_ai_life 版（実績がまだ小さいので「実験記」軸で再構築）:

### 3. 削除リスク回避（Threads8 教訓）

- 「月100万」「収益化」「マネタイズ」を表に出さない
- 「実験」「記録」「過程」を主語に
- 「誰でも稼げる」「初心者でも」系の煽りはゼロ
- DM 勧誘はしないと明記

## 固定投稿案 (v1)

```
駆け出し SE × AI の実験記｜2 年目

▶ AI に会社作らせて Day 1 で 1 日 5 投稿の体制構築
▶ AI 生成 220 字を 119 字まで削った編集記録
▶ note 売上 0 円スタートの全プロセス公開
▶ Threads × note × Claude Code の作り方を文書化

「AI 副業始めたい会社員 / ぼくと同じ立場の駆け出し SE」へ
完成された成功談じゃない、いま動いてる実験の隣で見てください。

進捗の全部は note の連載で記録中
→ note.com/gaku_ai_life

※ぼくから DM で勧誘は一切しません。
　なりすましの DM が来たら教えてください。
```

### この設計の根拠

| 行 | 役割 | 元ネタ |
|---|------|-------|
| 1 行目 | コンセプト宣言 | インスタハカセ式肩書 |
| 2〜5 行目 | 実績羅列 = 複数オファー入口 | インスタハカセ式 |
| 6〜7 行目 | 誰向け＋過程を見せる | あわを。式 + ソーダ式 |
| 8〜9 行目 | note 連載へのオファー | ひで式（フロー→ストック） |
| 末尾 | DM 勧誘しない宣言 | あわを。アカウント削除考察対策 |

## 投稿からの誘導フレーズ集

固定投稿のどの行を匂わせるかで複数パターン作れる。

- 「AI に会社作らせる手順は固定投稿に置いてます」
- 「119 字に削った編集記録は固定投稿から見れます」
- 「note 連載の続きはプロフィールから」
- 「Day {N} までの全プロセスは固定投稿に」

これらを当たり訴求とセットで投稿すると自然な導線になる（投稿 3 回に 1 回まで・Threads8 教訓）。

---

## 改訂タイミング

- **毎週月曜**: 数字を更新（Day {N}、フォロワー数、最新の実績）
- **当たり訴求が変わった時**: 即日改訂
- **削除リスクワード検出時**: 即日改訂
- **note 連載に新章追加時**: 該当章を実績羅列に追加

## 次の節目で追加する実績候補（先行設計）

| 達成条件 | 追加する実績文 |
|---------|--------------|
| フォロワー 500 人 | 「Day {N} で 134→500 人到達」 |
| 初回コメント反応 50+ | 「1 投稿で 50 コメントもらった時の構造分析」 |
| note 初収益 | 「note 初収益◯◯円までの全プロセス記録」 |
| 月商 1 万円 | 「実験 ◯日目で月 1 万円到達した時の動き方」 |
| 月商 10 万円 | 「Day {N} で月 10 万円達成。連載 Ch.2 公開」 |

実績は時間軸 (Day {N}) と数字でしか語らない。「すごい成功」「劇的に伸びた」みたいな主観表現は使わない。
