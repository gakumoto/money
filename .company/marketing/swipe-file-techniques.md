# 転用できる型ライブラリ（gaku版）

5,000円noteから、**ジャンル(アダルト)と売り方(煽り)は捨てて、構造だけ**を抜き、gakuのAI副業ジャンルに翻訳したもの。投稿生成・note制作で参照する。

## ⚠️ 真似しないもの（gakuは逆を行く）
- 借金どん底→月100万／「人生変わった」／「最後の商材」／値上げ煽り「今が最安」。
- これらは コア（盛らない・地味・つまらんけど）と削除リスク管理に反する。gakuの武器は逆＝**0円を正直に出す誠実さ**。

## 使える型① アカウント設計5要素
ターゲット / ジャンル / キャラ / アカウント名 / プロフィール を一貫させる。
→ gaku版は確定済み: ターゲット=5年前の自分(コミュ障/一人で稼ぎたい)、約束=人に会わずAIと一人で、声=つまらんけど。

## 使える型② バズ投稿5型（毎投稿どれかに当てはめる）
1. **問いかけ型**: 問い→共感→ヒント/続き。YESで終わる問いはNG、自分を振り返らせる問いに。
2. **暴露型**: 「ぶっちゃけ◯◯」衝撃の一文→具体例→だからどうする。
3. **リスト型**: 「◯◯な人の特徴」3〜7個(理想5)→オチ。保存されやすい。
4. **断定型**: 「◯◯しろ/◯◯はいらない」言い切り→理由→対比。
5. **ストーリー型**: 失敗/過程を時系列で。
→ gakuは①問いかけ・⑤ストーリー(過程開示)・②暴露(本音)が相性◎。

## 使える型③ note導線
- **ピン留め(固定)**で新規訪問者をフォロー&note誘導（実装済み）。
- **未完型**: 投稿で全部語らず「続きは固定/noteに」と匂わせる。
- **「これ私のことだ」**: ターゲットを具体化(例「副業したいけど人に会うの苦手な会社員」)。

## 使える型④ 売れるnoteのセールスレター構造
痛み共感 → 転機(出会い) → 変化(実績) → なぜ可能か → 手に入る未来 → Q&Aで不安潰し → オファー。
→ gaku版: 数字は盛らず実数(0円/フォロワー実数)。煽らず「同じ立場の人へ」で差し出す(売りつけない)。

## 使える型⑤ プロフィール5要素
何者か / 権威 / ターゲットへの呼びかけ / 得られる価値 / CTA。
→ 実装済み（コアの声で）。

## ひとことルール
**型は借りる。声とトーンは借りない。** 同じ構造でも、煽れば情報商材・正直に語ればgaku。常に後者。
