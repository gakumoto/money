# gaku_ai_life 1日5投稿フレームワーク

## 目的
- 月7桁収益を支えるリーチを最速で確保する
- AIスタッフが量産可能な型を確立し、半自動化のベースを作る
- 投稿の型と時間帯を固定して、判断回数をゼロに近づける（オーナーは意思決定だけ）

## 全社ライティングルール（投稿前に必ずチェック）
- ❌ 「〜かもしれません」「〜だと思います」 → **断定する**（注: 「だ・である調」のことではない。ですます調でもOK）
- ❌ 「皆さん」「皆様」 → **1人称（あなた / 君）で話しかける**
- ❌ 本文中の絵文字 → **不使用**（プロフ欄のみOK）

## オーナー（gaku_ai_life）の自然な口調

**基本は「ですます調」**。「だ・である調」で固めると硬すぎる。

### OK パターン
- 「やめた方がいいです」「向き合います」「組みました」「単純です」
- 「正直、続くか自信ないです」「ぼくはまだ0円です」（弱さを開示）
- 「〜なんですよね」「〜なんです」（柔らかい断定）

### NG パターン
- 全文「だ・である調」で押し切る（ビジネス書っぽくなる）
- 「○○ということが本質だ」「○○になる」みたいな格言・哲学調
- 完璧な姿勢を見せる。弱さを隠す

## 各型のテンプレ（AIスタッフが使う雛形）

### 1. 朝・学び共有型（07:30）

**構造**
```
[1行フック：気づきの結論を断定で]

[なぜそう言えるか：1〜2文の根拠]

[君への問いかけ or 行動喚起]
```

**例（ですます調基本）**
```
AIに任せた方が早い仕事と、自分でやった方が早い仕事って、けっこう違います。

ぼくは昨日、AIにDB設計を投げて3時間ハマりました。最終的に自分で書いた方が30分で終わったんです。

君の業務でAIに任せていい仕事はどれですか？
1つだけ教えてください。
```

### 2. 昼・進捗報告型（12:30）

**構造**
```
note収益化チャレンジ Day {N}

[今日やってること：1〜2行]

[ここまでの数字：フォロワー / 投稿数 / インプ / 進捗％]

[今日のミニ目標]
```

**例（ですます調基本）**
```
note収益化チャレンジ Day 22です。

今日は1本目の有料記事の構成を詰めています。

現在地：フォロワー134 / 投稿数 65 / 累計売上 0円。
正直まだ売れる気がしないですけど、続けます。

今日のミニ目標は構成を3章まで書き切ること。
```

### 3. 夕・失敗オープン型（18:00）

**構造**
```
[失敗の事実：1行で]

[何が起きたか：2〜3行]

[原因と次の手]
```

**例（ですます調基本・弱さ開示型）**
```
昨日の投稿、全部スベりました。

エンジニア向け技術用語を多用しすぎて、副業希望の会社員には意味不明だったんです。インプレッションは半分以下。

正直、ちょっと凹んでます。
次の手：技術用語を出すときは必ず「これは○○ということ」と言い換えを付けます。
```

### 4. 夜・振り返り＋明日宣言型（21:30）

**構造**
```
今日の学び3つ
1.
2.
3.

明日やること1つ
-
```

**例（ですます調基本）**
```
今日の学び3つです。

1. 進捗投稿は「数字」を入れた方が3倍読まれる
2. 失敗投稿は反応が一番厚い
3. プロフィール改修は週1回で十分

明日やることは1つ。
有料記事の Part 1 を書き切ります。
```

### 5. 深夜・思考/note誘導型（23:00）

**構造**
```
[抽象度高めの問い or 仮説：2〜3行]

[君の意見を求める一文]

[長文版はnoteへ：note.com/gaku_ai_life]
```

**例（ですます調基本・弱さ開示）**
```
副業で稼ぐのに必要なのって、才能じゃないと思うんです。
たぶん、続けられる仕組みです。

ぼくは才能のない側の人間なので、AIと組んで仕組みで戦っています。
正直、自分の力だけだったら半月で諦めてました。

君はどっちの戦い方をしていますか？

長文版はnoteに書きました：note.com/gaku_ai_life
```

## 拡張型（2026-05-13 追加・Threads2-8 学習統合・1日10投稿体制への布石）

コア 5 型に加えて、Threads2-8 で実証された伸びる型を 6 つ追加。AIスタッフは時間帯と型をペアで判断する。

### 6. 共感あるある型（任意時間・短文）

ソーダ式「ユーザーは暇つぶしで見ている」を体現。3 行以内、深く考えない。

**構造**
```
[共感トリガー：ぼく主観で1行]

[気持ちの中身：1行]

[同類への呼びかけ：1行]
```

**例**
```
正直、朝の Threads って一番開きにくいです。

通知だけ見て閉じてる時、ありませんか？

ぼくはいつも 2 回開き直してます。
```

### 7. 質問型（任意時間・コメント誘発）

ソーダ式。投稿の最後に「あなたはどう思う？」「教えてください」で締める。

**構造**
```
[二択 or 開いた問い：1〜2行]

[自分の答え：1行（オプション）]

[相手への呼びかけ：1行]
```

**例**
```
コードレビュー、AI に投げる派？人に投げる派？

ぼくは最近 9 割 AI に投げてます。

君はどっちですか？
```

### 8. 実績スクショ型（夜 or 深夜・短文+画像）

ソーダ式「実績+短文+スクショ」。成長過程を見せる時の最強型。

**構造**
```
[1 行で実績：数字を入れる]

[一言コメント：1行]

[スクショ画像添付]
```

**例**
```
おおー、Day 22 でフォロワー 150 人超えました。

134 → 150 まで 9 日かかりました。
```

### 9. 当たり訴求型（任意時間・★最重要・1日2本は出す★）

インスタハカセ公式「(自分は何者か) × (気づき1つ)」。投稿の 7 割はこれで作れる。

**(自分は何者か) パターン**:
- 「フォロワー 134 人の駆け出し SE のぼくが、」
- 「note 売上 0 円のぼくですが、」
- 「AI に会社作らせて Day 22 のぼくが、」
- 「相談相手 AI だけの 2 年目 SE が、」
- 「社内エンジニア 1 人で抱えてる立場で、」

**(気づき1つ) パターン**:
- 「コードレビューは AI 任せが楽すぎる」
- 「副業ノウハウより、まず投稿の型を 1 つ固定する方が早い」
- 「AI に下書き 10 本作らせる方が、自分で 1 本書くより早い」

**例**
```
note 売上 0 円のぼくですが、AI に下書き 10 本作らせる方が、自分で 1 本書くより早いと気づきました。

自分で書くと 1 本 30 分。
AI に投げると 10 本 5 分。

そこからフィードバックして 119 字まで削る方が、結局自分の言葉に近づきます。
```

### 10. 深夜起きてる型（深夜・参加型）

ソーダ式。深夜は反応率が一気に上がる時間帯。「起きてる人いる？」だけで参加が集まる。

**構造**
```
[時間言及 or 状況描写：1〜2行]

[起きてる人への呼びかけ：1行]
```

**例**
```
深夜にコード書いてる人、いますか？

ぼくはいま AI と一緒にバグ追ってます。
```

### 11. リライト型（任意時間・1日1本まで）

過去の伸びた投稿をそのまま or 微改変で再投稿。Threads アルゴリズム上、コピペでも当たる。

**ルール**
- 直近 1 ヶ月で平均インプの 2 倍以上取れた投稿が対象
- 再投稿の間隔は最低 7 日空ける
- 全く同じテキスト or 1 文だけ変える、のどちらか
