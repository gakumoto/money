# gaku_ai_life Phase 2 投稿ルーチン（30日実験版）

## このルーチンの目的

**仮説を30日間そのまま実行して、データで答えを出す。**

140本分析で見えた3つの発見を、本当に再現するか検証する：
1. 弱さ開示型は他カテゴリの 5 倍伸びるか（n=4 の検証）
2. 9時 / 22時 は本当にゴールデンタイムか（n=5+21 の精度UP）
3. 未完型は劇薬か / 何回で陳腐化するか

このルーチンで集めたデータが、Phase 3 の有料記事「設計通り運用したらこうなった」の素材になる。

---

## 設計の3原則

### ① 投稿数を絞る（6.5本/日 → 2-3本/日）
Phase 1 の 1日6.5本ペースから、9時 + 22時 + 任意13時 の **1日2-3本** に絞る。
量より配置精度を取る。「全時間帯打ち」をやめる。

### ② テーマを固定ローテーション
曜日別に「9時の型」「22時の型」を決め打ち。
毎日の判断回数をゼロにする → 制作疲れを防ぐ。

### ③ 弱さ開示を週2本「死守」
4本サンプルの仮説を、30日で 8〜12 本の中サンプルに育てる。
弱さ開示を意識的に増やさないと、永久に検証できない。

## 朝と夜の役割分担

### 9:00 の主砲（朝の型）
- **目的**：新規リーチ獲得・通勤/起床直後の人にスクロールを止めさせる
- **トーン**：素直・正直・本音寄り
- **長さ**：**2〜4行死守**（バズリファレンス @mens_threads_ の3パターンが全部3〜5行で勝負している。短さがリーチを取る）
- **テーマ**：弱さ / 共感 / 問い → **重い投稿** をこの時間に置く
- **制作**：前夜22-23時に下書き、朝6:30に最終チェック

### 22:00 の主砲（夜の型）
- **目的**：1日の総まとめ・反応のピーク回収
- **トーン**：振り返り・思考・落ち着いた語り
- **長さ**：中（3〜6行）
- **テーマ**：振り返り / 思考 / 報告 → **整理された投稿**
- **制作**：21時に下書き、22時にチェック → 投稿

### 13:00 の追加弾（任意）
- **目的**：朝投稿の反応をブースト（コメント返しの呼び水）
- **トーン**：軽め・雑談寄り
- **長さ**：超短（1〜2行）
- **テーマ**：軽い気づき / 雑談 / 進捗の一コマ
- **制作**：その場で書く・推敲しすぎない
- **省略可**：余裕がなければ無理しない

## 型ごとの簡易テンプレ

### 弱さ開示型
**冒頭枕詞は「勇気出して言うけど」「正直」「ぶっちゃけ」のいずれか必須**。
2026-05-20 のバズリファレンス分析で、@ao_maru_ao「勇気出して言うけど…30代なのに貯金100万円ありません」が **200K views / 2,900 likes**（いいね率1.45%・極めて高い）を出したため、この枕詞を Phase 2 では必須化。

```
[勇気出して言うけど / 正直 / ぶっちゃけ]、
[自分の失敗・できていないこと]、
[具体的な数字 or 期間]です。

[同じ状況の人への問いかけ or 一言]
```
**例**：「ぶっちゃけ、3日連続で書いた投稿、全部100views以下です。やめたくなりますね。」

### 日常共感型
```
[誰でも経験がある日常の一コマ]。

[問いかけ or 余韻で終わる]
```
**例**：「電車でThreads開いたら、隣の人もThreads開いてた。」

### 問いかけ型
```
[シンプルな問い]
[なぜ聞きたいかの一文]
```
**例**：「note最初の月、いくら稼げました？ぼくはまだ0円です。」

### 未完型（劇薬・週1まで）
**語尾は「は、」「..」「↓」で完全切断する**。
バズリファレンス（@fubuki.0up「もっと大切な、❿は、」/ @oniduka_blog「具体的な手順は、」/ @mens_threads_「これやって..↓」）の共通パターンを採用。

```
[今やろうとしていること]、
[未完語尾：「は、」「..」「↓」のいずれか]
```
**例**：「投稿、ちゃんと考えて書く、、、」「具体的な手順は、」「これやって..↓」

### 振り返り型
```
[今日 / 今週やったこと]、
[気づいたこと1つ]
[明日 / 来週やること]
```

### 思考型
```
[ふと考えていること]、
[展開2-3行]
[読者を残す一言]
```

### 進捗報告型
**数字は千円単位・実数まで出す**。「月50万円」じゃなく「月501,060円」で書く。
バズリファレンス（@fubuki.0up「501,060円」/ @rin.noter「¥1,745,600円」）の細かさが「リアル感」を生む。万円・百万円単位の丸め数字は弱い。

```
[実験 Day ○]
[今日の数字（千円・百views単位まで実数）]
[次の動き]
```

### AIノウハウ型（命令型で書き直す）
**提案型じゃなく断定命令で書く**。「〜がおすすめ」→「これだけはやれ」。
バズリファレンス（@oniduka_blog「Claude Code初日、これだけはやれ」14.9K views）の構造を採用。ぼくの過去のAIノウハウ系は提案型で平均160views止まりだったため、Phase 2 では命令型に変える。

```
[テーマ]、これだけはやれ。
・[手順1]
・[手順2]
・[手順3]
[所要時間 + 切迫感]
```
**例**：「Claude Codeの最初の30分、これだけはやれ。・〇〇 ・△△ ・□□ 今夜やれ。」

## 緊急停止 / 設計変更条件

下記が起きたら即停止・再設計：

- ❌ **未完型が月5本以上**：陳腐化進行・即減らす
- ❌ **弱さ開示の平均が他カテゴリと差が出ない**（Day 14時点で集計）：仮説外れの可能性、内容を精査
- ❌ **9時/22時の平均viewsが Phase 1 期間より下がる**：投稿数減らしすぎ → 13時の追加弾を週5以上に増やす
- ❌ **30日中5日以上、9時 or 22時の投稿を落とした**：実験設計が崩壊、再起動
- ❌ **「収益化」「マネタイズ」「稼ぐ」を本文に入れた**：Phase 2 は売らない設計、即削除

---

## やってはいけないこと

- ❌ Phase 2 期間中に **note 有料記事を公開する**（C案違反 / 0円矛盾の再来）
- ❌ Phase 1 で当たった訴求を**まだ出てない次の流行に乗り換える**（変数増やしすぎで検証不可になる）
- ❌ 反応が悪い日に**型を変える**（30日固定が大原則）
- ❌ **告知投稿の連発**（誘導比 1/3 死守）
- ❌ 「数字に揺れて朝6時投稿を試したくなる」（6時台は平均81views で外れ枠と判明済み）

## このルーチンの「成功定義」

30日後（Day 44 / 2026-06-26）、下記のうち **2つ以上満たせば成功**：

1. 弱さ開示8〜12本の平均が、他カテゴリ平均より明確に高い（仮説検証OK）
2. 9時 / 22時 の平均viewsが Phase 1 期間より上昇（時間帯仮説OK）
3. 平均views全体が Phase 1 期間より上昇（量より質の証明）
4. フォロワー +3,000 以上（成長加速）
5. Phase 3 の有料記事の構成が、データから自然に書ける状態になっている

**1つしか満たせない場合**：仮説の一部が外れた → そのまま正直に有料記事に書く（盛らない人ブランドが活きる）
