# gaku_ai_life 保存狙い投稿システム

## 目的
- Threadsで止まってもらうだけでなく、あとで見返してもらう投稿を増やす
- Threadsからnoteへの導線を、売り込みではなく実用価値でつなぐ
- 短い本文と画像を分業させて、量産しやすくする

## 保存される投稿の定義

保存されるのは、共感した投稿より、
あとで自分に使えそうな投稿。

このアカウントでは次の3条件を満たすと強い。

1. 今日の自分にすぐ使える
2. 1投稿1テーマで迷わない
3. 画像1枚で見返せる

## 基本構造

### 本文の役割
- 1行目で止める
- なぜその画像を見るべきかを1つだけ伝える
- 弱さを1か所だけ入れる
- 最後は 保存して見返せる と伝える

### 画像の役割
- 実際に保存する理由を置く
- 3〜5項目で完結させる
- 読み返したときに行動に移せる順番にする

## このアカウントで相性がいい保存テーマ
- note導線の見直し
- note1本目で捨てるもの
- 帰宅後の副業ルーティン
- Claudeへの指示テンプレ
- 0円期の見方

## 画像ルール

### 形式
- 4:5縦長 1080x1350
- 1枚完結でも可
- 3〜5枚カルーセルでも可

### 見た目
- 背景は明るい生成り or 薄いグレー
- 文字色は黒に近い濃色
- 差し色は深緑 or 紺を1色だけ
- 余白を広く取る
- 装飾より可読性優先

### レイアウト
- 1行目: タイトル
- 2ブロック目: 3〜5項目の要点
- 最下部: `Gaku@趣味でアプリつくるもの`

### NG
- 文字を詰め込みすぎる
- 1枚に2テーマ入れる
- 売り文句を前面に出す
- 技術用語だけで終わる

## 本文テンプレ

```markdown
[固有名詞 + 数字の1行目]

[そのテーマが必要な理由]

[自分の弱さ or 詰まった話]

画像にまとめました。
保存して、
あとで見返せます。
```

## 画像テキストテンプレ

```markdown
[タイトル]

1. [要点]
2. [要点]
3. [要点]
4. [要点]
5. [要点]

Gaku@趣味でアプリつくるもの
```

## CTAルール
- 保存してください は毎回書かなくていい
- 保存して、あとで見返せます のように用途で伝える
- noteリンクは保存投稿では前面に出さない
- noteはプロフィール or 固定投稿導線に任せる
