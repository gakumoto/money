# /ask やり取り

## 🔹 指示

YouTubeのリサーチできる？必要ならURLとかキーワード教えるけど？

## 🔹 Claude の応答

できます。`youtube-research` スキル経由で動きます。

## できること
- 指定動画 / 指定チャンネル直近動画の **字幕取得 → 要約 → Threads 投稿ネタ抽出**
- 抽出ネタは `.company/research/topics/inbox/<日付>_youtube_<slug>.md` に蓄積
- 後で `/post_bulk` / `/create_post_from_idea` で投稿生成に使う流れ

## 欲しい情報 (どれか)
1. **動画 URL** (1 本 or 複数) — 一番速い
2. **チャンネル URL** + 「直近 N 本」 — チャンネル丸ごとスキャン
3. **キーワード** + 「直近 ◯ ヶ月で再生数 ◯ 以上」みたいな条件 — まず WebSearch で候補出してから精査
4. **競合発信者の名前** — gaku_ai_life 文脈なら「ひで」「インスタハカセ」「あわを。」「ソーダ」「suisuinote」など過去参照してる人の最新動画

## 注意点 (事前共有)
- 字幕が無い動画 (or 自動字幕オフ) は要約できないので、その場合は別動画に振り替え
- 抽出するネタは gaku_ai_life の **削除リスク管理** (「月100万」「ガチで損する」連発NG) に通してから inbox に保存
- フックは A〜H のバリエーション集に必ず分類して、画一化を防ぐ

URL / チャンネル / キーワード、どれで投げますか？こちらから候補を出すなら「直近 1 ヶ月の AI 副業系で伸びてる Threads 解説動画」あたりを WebSearch + youtube-research で当たれます。
