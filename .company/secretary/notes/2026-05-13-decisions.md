### 11. フィードバック蓄積システムを実装（AIスタッフ育成の核）

- **背景**: スキルだけ作っても、出てくる投稿が「君が書いた感じ」にならない。フィードバックを永続化して、AIスタッフが毎回読み込んで成長する仕組みが必要
- **判断**: 以下を実装

  - `.company/marketing/feedback/<account>.md` 新設（2アカウント分）
  - `/feedback` スキル新設（蓄積追加の窓口）

- **理由**:
  - フィードバックは「何を・どう直すか」まで書くことで初めてAIが学習できる
  - 「冒頭が弱い」では意味がない。「冒頭1行に固有名詞がない。○○を実名に置き換える」が正解
  - 同じ指摘を10回入れていい。蓄積が増えるほど精度が上がる
  - Claude Code のフォルダ運用だから永続化できる（ChatGPTでは不可能な強み）
- **対応部署**: 全社 + marketing + skills 全て
- **フォローアップ**:

### 15. 初の本格的なフィードバック蓄積（AIスタッフ育成の1回目）

### 13. Windows Task Scheduler への登録（完全自動化の完成）

  - PS 5.1 で `[System.IO.Path]::GetTempFileName()` の挙動が不安定なため GUID ベース絶対パスに変更
  - 各スクリプトに `sys.stdout.reconfigure(encoding='utf-8')` も追加（Windows + Python 3.14 用）
  - .ps1 形式の Claude CLI を subprocess から呼べるよう nightly_pipeline.py を改修
- **動作検証**:

  - threads_auto_post.py --dry-run で queued の publish_at 判定が正しいことを確認（明日7:30まで保留）
