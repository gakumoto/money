## 構成

### ① 無料パート（冒頭・ここで"買う理由"を作る）

```
「AIで副業」が気になる。でもコードなんて書けない。
——そんな人へ。

ぼくは2年目のSEだけど、最近作ったアプリのコードは、ほとんど自分で書いてません。
AIに「こういうのが欲しい」と伝えただけ。

この記事では、ぼくが実際に、コードを（ほぼ）書かずに自分用のアプリを作った手順を、
最初から最後まで、つまずいたところごと全部公開します。

「自分には無理」と思ってる人が、「あ、これならできるかも」になる。
そこまで持っていくのが、この記事の目的です。

ここから先、具体的な手順です。
0円のぼくが言うのもなんですが、買って損はさせません。
```

### ② 有料パート（実手順・2026-06-10 本人ヒアリング反映）

ツール=Claude Code / 作ったもの=発信ツール(myCompany) / コード知識不要（本人確認済み）。

```
## 使ったもの

- パソコン1台（Windows でも Mac でも）
- Claude の「Pro」プラン … 月 2,000 円くらい
  - ぼくは最初 Pro で始めて、本格的に使うようになってから Max（月 8,000 円くらい）に上げました。**最初は Pro で十分**です。
- 「こういうの欲しい」という、ふわっとしたアイデア1個

これだけ。プログラミングの本も、勉強も、APIキーも、いりません。

## 手順

ステップ1：Claude を入れる（アプリを入れるだけ・5分）
唯一の"技術っぽい"ところだけど、いまは**アプリを入れるだけ**でいけます。黒い画面（ターミナル）は触りません。

1. 公式サイトから「Claude」アプリをダウンロード（Windows / Mac 両方あり）
2. インストールして開く → ログイン
3. 画面上の「**Code**」タブを押す
4. 使うフォルダを1つ選ぶ → 準備完了

〔ここに実際のダウンロード画面 / Codeタブの画像を入れると、一気に親切になる・画像推奨〕

ステップ2：作りたいものを、日本語で伝える
ぼくはこう言いました。
「自分のSNS投稿の下書きをためて、OKを押したら自動で投稿できるツールが欲しい」
それだけ。設計もコードも、AIが考えて書いてくれます。

ステップ3：「ここ違う」と返す
出てきたものを見て、気に入らないところを日本語で伝える。
「もっとシンプルに」「スマホで見れるように」「この機能も欲しい」
これを何回か繰り返すと、形になっていきます。

ステップ4：動かして、確認する
「動かして」と言えば、起動まで手伝ってくれます。
実際に触って、また直して、の繰り返し。

ステップ5：使いながら、育てる
完璧を目指さない。「ここ不便」が出たら、また話す。
ぼくのツールも、いまだに育て続けてます。

## つまずいたところ（正直に）

- あなたが最初に作るのは、こんな大げさなものじゃなくていい。「毎日ちょっと困ってること」を1個、AIに話すところから。
```
