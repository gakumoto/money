# コードゼロで、AIに"自分用アプリ"を作らせた全手順

「AIで副業」が気になる。でもコードなんて書けない。
——そんな人へ。

ぼくは2年目のSEだけど、最近作ったアプリのコードは、ほとんど自分で書いてません。
AIに「こういうのが欲しい」と伝えただけ。

作ったのは、自分の発信（Threadsとnote）を楽に回すためのツール。
投稿の下書きをためて、スマホでOKを押すと公開される、みたいなやつです。

この記事では、それを**コードの知識ゼロで**——正確には、コードを一行も自分で書かずに——作った手順を、つまずいたところごと全部公開します。

正直に先に言うと、「ぜんぶ簡単」ではないです。
最初のセットアップだけは、ちょっと"技術っぽい"。
でも、そこさえ越えれば、あとは**ぜんぶ日本語の会話**で進みます。コードは一度も読みません。

「自分には無理」が「あ、これならできるかも」になる。
そこまで持っていくのが、この記事の目的です。

0円のぼくが言うのもなんですが、買って損はさせません。

## 使ったもの

- パソコン1台（Windows でも Mac でも）
- Claude の「Pro」プラン … 月2,000円くらい
  - ぼくは最初Proで始めて、本格的に使うようになってからMax（月8,000円くらい）に上げました。**最初はProで十分**です。
- 「こういうの欲しい」という、ふわっとしたアイデア1個

これだけ。プログラミングの本も、勉強も、APIキーも、いりません。

## 手順

**ステップ1：Claudeを入れる（アプリを入れるだけ・5分）**

唯一の"技術っぽい"ところだけど、いまは**アプリを入れるだけ**でいけます。黒い画面（ターミナル）は触りません。

1. 公式サイトから「Claude」アプリをダウンロード（Windows / Mac 両方あり）
2. インストールして開く → ログイン
3. 画面上の「**Code**」タブを押す
4. 使うフォルダを1つ選ぶ → 準備完了

〔ダウンロード画面 / Codeタブの画像を入れると親切・任意〕

**ステップ2：作りたいものを、日本語で伝える**

ぼくはこう言いました。
「自分のSNS投稿の下書きをためて、OKを押したら自動で投稿できるツールが欲しい」
それだけ。設計もコードも、AIが考えて書いてくれます。

**ステップ3：「ここ違う」と返す**

出てきたものを見て、気に入らないところを日本語で伝える。
「もっとシンプルに」「スマホで見れるように」「この機能も欲しい」
これを何回か繰り返すと、形になっていきます。

**ステップ4：動かして、確認する**

「動かして」と言えば、起動まで手伝ってくれます。
実際に触って、また直して、の繰り返し。

**ステップ5：使いながら、育てる**

完璧を目指さない。「ここ不便」が出たら、また話す。
ぼくのツールも、いまだに育て続けてます。

## 実況中継：ひとつ、目の前で作ってみます

手順だけだとイメージが湧かないと思うので、
後ろの10案にある「今日やること3つだけTODO」を例に、実際の流れを見せます。

**あなた：**
```
今日やることを3つだけ書けるTODOツールが欲しいです。
ぼくはプログラミングが分かりません。
専門用語を使わずに進めてください。
途中で確認したいことがあったら、選択肢で聞いてください。
```

**AI：**
「わかりました。確認させてください。
A. パソコンのブラウザで開く形でいいですか？
B. デザインはシンプル／かわいい／かっこいい、どれにしますか？」

**あなた：**
「Aで。シンプルで。」

**AI：**
（1〜2分、勝手に作業して）
「できました。動かしてみますか？」

**あなた：**
「動かして」

→ ブラウザにTODOが表示される。もう動いてます。

**あなた：**
```
ここが違います。
いま：4つ以上書けてしまう
してほしい：3つまでしか書けないように
```

**AI：**
「直しました。」

——こんな感じで、**会話5往復くらい**で最初の1個ができます。
時間にして30分くらい。
「プログラミングをした」感覚は、たぶんゼロです。

## コピペで使える「最初の一言」

手順は分かっても、最初の一言が出てこない。
そんな人のために、そのまま貼って使える形を置いておきます。

```
〇〇ができるツールが欲しいです。

ぼくはプログラミングが分かりません。
なので、専門用語を使わずに進めてください。
途中で確認したいことがあったら、選択肢で聞いてください。
```

ポイントは2つ。

- **「プログラミングが分かりません」と最初に言う**こと。AIが説明の仕方を変えてくれます。
- **「選択肢で聞いて」と頼む**こと。「どうしますか？」と丸投げされて困る、が無くなります。

## 「直してほしい時」の伝え方

ここで挫折する人が、たぶん一番多いです。
コツは、**「いい感じにして」と言わない**こと。それだとAIも困ります。

ぼくがいつも使ってる形はこれ。

```
ここが違います。
いま：〔いまどうなってるか〕
してほしい：〔どうなってほしいか〕
```

例えばこう。

```
ここが違います。
いま：文字が小さくて読みにくい
してほしい：スマホでも読みやすい大きさに
```

「いま」と「してほしい」を分けるだけで、直り方がぜんぜん変わります。

ビフォーアフターも置いておきます。

- ✕「いい感じにして」→ ○「文字を大きく。色は白っぽく」
- ✕「なんか違う」→ ○「いま：ごちゃごちゃして見える／してほしい：ボタンを2個に減らす」
- ✕「全部直して」→ ○「まず、この1個だけ直してください」

一度に1個ずつ。これがいちばん早いです。

## 詰まった時の魔法の言葉

エラーっぽい赤い文字が出たら、こうしてください。

**そのままコピーして、貼って、「これ直して」。**

以上です。
エラーの意味を理解する必要はありません。読まなくていいです。
ぼくもSEのくせに、半分くらいはこれで済ませてます。

あと、何をしていいか分からなくなったら、これも効きます。

```
いま何がどこまでできてますか？
次にぼくは何をすればいいですか？
```

AIは現状整理が得意なので、迷子になっても戻ってこれます。

## 場面別・そのまま使える言い方集

よく使う場面の「言い方」をまとめておきます。
作りながら困ったら、ここに戻ってきてください。

**見た目を変えたい**
「もっとシンプルな見た目にしてください」
「スマホで開いても崩れないようにしてください」

**機能を足したい**
「〇〇の機能を足してください。いまあるものは壊さないでください」

**翌日、続きをやりたい**
「昨日の続きです。いま何ができてる状態か教えてください」

**何をしたのか知りたい**
「いま何をしたのか、専門用語なしで説明してください」

**わからない言葉が出てきた**
「その言葉が分かりません。別の言い方で言い直してください」

**やり直したい**
「さっきの状態に戻してください」

**完成かどうか判断してほしい**
「これで完成にしていいですか。足りないものがあれば教えてください」

## 最初に作るといいもの（10案）

「作りたいものが思いつかない」も、よくある詰まりです。
大げさなものじゃなくていい。**「毎日のちょっと面倒」**から選んでください。

1. 家計のレシートをメモするだけの記録ツール
2. 今日やることを3つだけ書くTODO
3. 子どもの行事や持ち物のチェックリスト
4. 飲んだサプリ・薬の記録
5. 筋トレ・体重の記録
6. 読んだ本と一言感想のメモ
7. 献立のローテーション表
8. 推しの配信スケジュール管理
9. SNS投稿の下書き置き場（ぼくはこれでした）
10. 「あとで読む」リンクのまとめ

コツは、**自分しか使わないもの**から始めること。
人に見せるものは、緊張するので2個目からでいいです。

## 逆に、最初はやめておいた方がいいもの

1個目では選ばない方がいいものもあります。

- お金のやりとりが発生するもの（決済など）
- 他人の個人情報を預かるもの
- 「人に売るためのもの」

理由は単純で、難易度が上がるし、失敗した時のダメージが大きいから。
まずは自分用。売るのは、作るのに慣れてからで間に合います。

## ぼくのツールが、育った順番

「使いながら育てる」のイメージが湧くように、ぼくの実例も置いておきます。
最初から今の形だったわけじゃないです。

1. 最初は「下書きを置いておく場所」だけ
2. 通勤中に見たくなって、スマホ対応
3. 見るだけじゃなく、OKボタンで投稿できるように
4. 決まった時間に、自動で投稿されるように
5. どの投稿が伸びたか、数字も見れるように

ここまで、一気にじゃなくて、数週間かけてちょっとずつ。
「ここ不便だな」が出るたびに、AIに話す。それだけでした。

最初の1個は、リストのどれかみたいな小さいやつでいい。
育てるのは、そのあとです。

## つまずいたところ（正直に）

- 一番の山は、ステップ1のセットアップ。ここで「うわ、難しそう」ってなる。でも越えれば天国。
- ぼくはSEなので、エラーの意味が分かる分ちょっと有利だったかも。でも**コードは書いてない**。
- あなたが最初に作るのは、こんな大げさなものじゃなくていい。「毎日ちょっと困ってること」を1個、AIに話すところから。

## よくある不安に、先に答えておきます

**Q. 変なこと言ったら、壊れない？**
壊れません。気に入らなかったら「さっきの状態に戻して」で戻せます。
そもそも自分用のツールなので、壊れても誰も困りません。安心して雑に試してください。

**Q. 英語できないけど大丈夫？**
ぼくも全部日本語でやってます。英語は一度も使ってません。

**Q. パソコン苦手でもできる？**
「アプリを入れて、日本語で話す」ができれば大丈夫です。
LINEが使えるなら、たぶんできます。
