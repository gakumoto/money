# note 収益化 導線設計（2026-06・okurihito 500円を主力に）

## ゴール
散らかった note 資産を **1本の出口（okurihito 500円）** に集約し、Threads のリーチを売上に変える最初の1本を売る。
※ 現状 0円。原因は「商品が無い」ではなく「**流れが繋がっていない・目立っていない**」。

## 導線マップ（これが今回の設計）

```
① Threads投稿（価値提供・型 D/H/C）
        │  9:1の"1"＝たまに軽く触れる
        ▼
② プロフィール（表示名＋bio＋note.com/gaku_ai_life）
        │
        ▼
③ 固定投稿（共感：人に会わず・0円・昔のぼくみたいな人へ）
        │
        ▼
④ 無料リード記事「コードを書かずに、AIに会社を作らせた話」（物語／なぜ・試食）
        │  末尾CTAで橋渡し（実装済み）
        ▼
⑤ 有料記事 okurihito 500円「自分専用ツール→自動投稿の全手順」← 出口
```

- **無料=「なぜ・どんな世界か」（物語）／有料=「具体的な作り方」（手順）** で繋ぐ。
- 無料④は okurihito の"手前の話"。読者が「で、どうやるの？」となった所で⑤に渡す（未完型）。

## 今回やったこと（このセッション）
- ④「AI会社を作らせた話」の末尾を **okurihito へ橋渡しするCTAに改稿**（「実験記」廃止名・「また書きます」予告も除去）。status を ready-to-publish に。
- 主力を okurihito 500円に確定（既公開・正直・ブランド一致）。

## 残ギャップと打ち手（★ gaku の手作業が要る所）
note の画面操作はこちらから不可。下記はオーナー作業：

1. **④ 無料記事を note に公開**（まだ未公開なら）。本文は `articles/2026-06-21_ai-company-build.md`。
2. **⑤ okurihito 記事の実URLを ④ の末尾に貼る**（今は profile URL で代用。記事URLに差し替えると遷移率↑）。
3. **note プロフィールで ⑤ を"注目記事"にピン留め**（playbook：ピン留めで遷移を作る）。
4. **固定投稿の導線を確認**：固定→note profile まではOK。可能なら固定本文からも④へ一言。

## Threads からのソフト誘導（9:1・削除リスク厳守）
- note 誘導は **1日1本まで**・リンク露出は全体の1/3以下。
- 売り込まない。「作り方は置いてある」程度の**未完型**で。
- 置き場所：7枠のうち **22:50(C・本音/節目)** か **16:30(F)** に月数回。毎日は出さない。
- 危険ワード（稼ぐ/収益化/月◯円）を売り文句にしない。「届けたい>売りたい」。

## KPI（出口の数字）
- note: 全体ビュー / ④の閲覧 / ④→⑤の遷移 / ⑤の購入数・売上
- まず測るのは **④の閲覧と④→⑤遷移**（ここが0なら導線が繋がってない）
- 初回購入が出たら playbook の段階値上げ（500→…）を検討。それまでは据え置き
