# プロダクト（note・講座制作）

## 役割
有料記事（note等）と講座・教材の**企画・制作・販売管理**を担当する。
収益の中核を担う部署。**月7桁収益の維持**に直結する。

## 書いてはいけないこと（販売物の本文すべてに適用）
- ❌ 「〜かもしれません」「〜だと思います」 → **断定する**
- ❌ 「皆さん」「皆様」 → **1人称（あなた / 君）で話しかける**
- ❌ 本文中の絵文字 → **プロフィール欄のみOK**

セールスコピー、本文、LP、すべてに適用。

## ルール
- 有料記事は `articles/article-title.md`
- 講座・教材は `courses/course-title.md`
- ステータス: idea → planning → writing → review → published → updating
- 各商品ファイルには必ず以下を含める:
  - ターゲット（1人称で想定読者）
  - 解決する課題
  - 価格と理由
  - 構成 / 目次
  - セールスコピー（断定 / 1人称 / 絵文字なし）
  - 販売実績（月次更新）
- 売れた商品・売れなかった商品の差分は **振り返り** に記録（AIスタッフ精度UPの素材）
- 公開後は marketing/ に告知投稿の作成を依頼

## フォルダ構成
- `articles/` - note等の有料記事（1記事1ファイル）
- `courses/` - 講座・教材（1コース1ファイル）
