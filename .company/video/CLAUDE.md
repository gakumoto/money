# 動画PR部門（Video）

## 役割
**顔出しなし × テキスト＋BGMの縦型スライド動画**を制作し、既存の AI 副業ブランド（gaku_ai_life）を PR する。
1本の縦型ショートを **Threads / Instagramリール / YouTubeショート** の3つに流し回す（1アセット→3配布）。
最終ゴールは Threads と同じ＝**リーチ拡大 → プロフ遷移 → note 導線**。

## 大原則（2026-06-26 立ち上げ時の決定）
- **顔出しなし**。画面・スライド・テロップ中心。声も当面出さない。
- **動画タイプ＝テキスト＋BGMの縦型スライド**（最速・量産・既存投稿文を流用できる）。
- **台本は"ゼロから書かない"**。Threads で**♡が付いた投稿（hook型 D/H/C）**をスライド割りして動画化するのが基本。
- **1アセット→3配布**。媒体ごとに作り直さない。微調整（尺・テロップ位置）だけ。

## 書いてはいけないこと（全社ルール準拠・必読）
動画のテロップ・概要欄・キャプションすべてに `.company/CLAUDE.md` のルールを適用：
- ❌ 曖昧表現（「かもしれません」「思います」）→ 断定
- ❌ 「皆さん」→ 主語なし問いかけ or 「あなた/君」
- ⚠️ 装飾絵文字NG。思考系（🤔🥹😌）は1画面に1個まで
- ⚠️ **危険ワード**（月100万/収益化/マネタイズ/月◯円）を売り文句にしない
- **9:1（有益:誘導）厳守**。note 誘導は控えめ・煽らない。リンク露出は全体の1/3以下
- **盛らない声**（[[gaku-real-voice-model]]）。投稿と同じ温度。動画だからと派手にしない

## フォーマット仕様（縦型スライド・標準）
- **解像度**: 1080×1920（9:16 縦型）
- **尺**: 12〜25秒（スライド5〜8枚 × 1枚2〜3秒）
- **構成**: ①フック（1枚目＝本文の強い1行）②本文（3〜5枚・1画面1メッセージ）③締め（余韻 or 控えめCTA）
- **テロップ**: 太め・大きめ・1画面1〜2行。背景は無地ダーク or やわらかいグラデ（装飾過多NG）
- **BGM**: 著作権セーフな穏やか系（ローファイ/アンビエント）。顔出しなしスライドに合う落ち着いた音
- **CTA**: 最後に控えめに「プロフィールに記録あります」程度。毎本売り込まない

## 制作パイプライン（3段階）
1. **企画（plans/）**: ♡が付いた投稿 or 新規ネタ → 動画台本（スライド割り）を storyboards/ に
2. **制作**: まず **CapCut テンプレで手動** に作りフォーマットを検証 → 形が決まったら **「投稿文→MP4自動生成」スクリプト**（ffmpeg/moviepy）で量産（SEらしく自動化）
3. **配布**: Threads（動画投稿）→ IGリール → YTショート。まず手動、慣れたら API 自動化

## KPI（Threadsの投稿KPIとは別管理）
- 動画別: 再生数 / 視聴維持率 / いいね / 保存 / プロフ遷移 / note遷移
- 媒体別: どの媒体でどの型が伸びるか（Threads/IG/YTで違う想定）
- 蓄積先: `.company/research/topics/video-pattern-YYYY-MM.md`（Threadsと同じ要領で月次分析）

## フォルダ構成
- `strategy.md` - 戦略・KPI・立ち上げ計画
- `plans/` - 動画企画（週次 or バッチ単位）
- `storyboards/` - 台本/スライド構成（1本1ファイル）
- `assets/` - 完成動画・素材（大きいファイルは git 管理外推奨）
