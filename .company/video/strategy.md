# 動画PR部門 戦略（立ち上げ）

- **何を**: 顔出しなし・テキスト＋BGMの縦型スライド動画
- **PR対象**: 既存の AI 副業ブランド（gaku_ai_life＝AI×副業×駆け出しSE）
- **誰に**: 5年前の自分＝人に会わず・コミュ障で、AIと黙々で稼ぎたい人
- **どこで**: Threads（主）→ Instagramリール → YouTubeショート（1アセット3配布）
- **ゴール**: リーチ拡大 → プロフ遷移 → note 導線（Threadsと同じ出口）

## なぜ動画か（勝ち筋）
- Threads/IG/YT すべてが縦型ショートを優遇 → **1本で3媒体ぶんのリーチ**
- 既存の**♡が付いた投稿（hook型 D/H/C）がそのまま台本**になる＝制作コストが低い
- 顔出しなしスライドは**量産・自動化が効く**（最終的に「投稿文→MP4」スクリプト化）

## 立ち上げ計画（最初の1〜2週間）
1. **フォーマット確定**: CLAUDE.md の標準仕様でテンプレを1つ作る（背景/フォント/BGM/尺）
2. **勝ちネタ3本を動画化**: `plans/2026-06-26_first-batch.md` の3台本を CapCut で試作
3. **3媒体に手動投稿**: Threads / IGリール / YTショート に同じ動画を流す
4. **数字を見る**: 再生数・視聴維持・プロフ遷移を比較し、**伸びたフォーマットを1つに決める**
5. **量産体制**: 決定形を「投稿文→MP4自動生成」スクリプトにして、Threadsの7本デーに動画も乗せる

## 制作ツールの方針
- **第1段階（検証）**: CapCut（無料・テンプレ・スマホ/PC可）で手動制作。まず"形"を当てる
- **第2段階（量産）**: フォーマット確定後、`scripts/` に **投稿文→縦型MP4生成**（ffmpeg or moviepy）を実装。テロップ自動レイアウト＋BGM合成。SEの強みを活かす自動化
- ※ いきなり自動化しない。**1つ伸びる形を見つけてから**コードに落とす（むだ撃ち防止＝Threadsと同じ教訓）

## 配布の現実
- **Threads**: API は画像対応済（`threads_auto_post.py`）。動画はまず手動投稿、後で video 対応を追加
- **IGリール / YTショート**: まず手動。慣れたら IG Graph API / YouTube API で自動化を検討
- リンク露出は1/3以下・9:1厳守（媒体が変わっても削除リスク管理は同じ）

## KPI / 分析
- 動画別: 再生数 / 視聴維持率 / いいね / 保存 / プロフ遷移 / note遷移
- 月次で `research/topics/video-pattern-YYYY-MM.md` に蓄積（Threadsの post-pattern と同じ運用）
- **最初の判断材料**: 3本×3媒体＝9データ点で「どの型×どの媒体」が動くかを見る
