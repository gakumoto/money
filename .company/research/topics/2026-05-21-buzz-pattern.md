## 共通する「型」5 要素

### 要素 1: 冒頭固有名詞 1 単語（最初の 1 〜 2 行）
- `サッカー日本代表`
- `栃木・強盗殺人`
- `三笘選手`

→ **アルゴリズム反応の引き金**。固有名詞 = 「これは何の話か」が 0.5 秒で判別できる
→ AI ノウハウ枠でも `Claude優秀` のように固有名詞があるが、その後の文字数が長い ← ここが差

### 要素 2: 極端な短文 (60-80 字)
- 🥇 約 60 字 / 🥈 約 35 字 / 🥉 約 30 字
- AI ノウハウ Top 4 (3,694 views) も短文 = 短さは伸びの必要条件

→ Threads アルゴリズムは「最後まで読まれる率」を見ている疑い
→ 短文 = 読了率 100% に近い

### 要素 3: 「逆説的」or「強い断定」で締める
- 🥇 「これをみてもいらんって言えるんですかね？」← 反論型問いかけ
- 🥈 「逮捕されないんですよ。」← 当たり前を断定する逆説
- 🥉 「受け止めれません。」← 主観を強く出す

→ **「同意する読者を呼び込む」or「反論したい読者を呼び込む」**
→ 結果として「返信 319」という異常エンゲージメント

### 要素 4: 主語なしの煽り感
- 全てに「ぼく / あなた / 君」がない
- でも「ぼくはこう思う」が透けて見える書き方

→ **「個人の主観」が読み手に届くが、押し付けがましくない**
→ 119 字版 v3 の呼吸と一致

### 要素 5: 「答えたくなる」構造
- 🥇 「言えるんですかね？」← 答えたい
- 🥈 「逮捕されないんですよ。」← 反論したい
- 🥉 「受け止めれません。」← 共感したい

→ Threads の評価軸は **「返信ラリー継続」** (D-028 リサーチ知見)
→ 1 投稿で完結させず「会話の種」を撒く

## AI/副業ジャンルへの転用テンプレ

「テーマだけ差し替え、型は固定」が基本。捏造 NG。

### テンプレ A: 「反論型問いかけ」(🥇 型)

```
[AI / 副業の固有名詞] [短い状況提示]
[逆説] って言えるんですかね？
```

例:
```
Claude Pro 制限きつくなったって言ってる人
これ見てもまだ Pro で粘りますか？
```

```
note 始めて 1 ヶ月 0 円のぼくが
「続ければ売れる」って信じれるんですかね？
```

### テンプレ B: 「当たり前を断定する逆説」(🥈 型)

```
[テーマ] [短い状況]
[読み手が見落としている事実] んですよ。
```

例:
```
AI 副業始めても
動かないと結局 0 円のままなんですよ。
```

```
プロンプト勉強しても
書く前から負けてる人は売れないんですよ。
```

### テンプレ C: 「主観をぶつける」(🥉 型)

```
いまだに [読み手が違和感もちそうな現状] を
[強い感情語で断定].
```

例:
```
いまだに Threads 1 投稿ずつ手で書いてる人を
心配する側に回ってしまいます。
```

```
いまだに ChatGPT だけで頑張ってる人を
時間がもったいないと感じてしまいます。
```

## 違反警告 (型だけ真似て中身を捏造しない)

- ❌ Sam Altman / Sundar Pichai の発言を「言ってた」と書く → 著名人発言は事実確認必須

- ❌ 「コードレビューしてみた」など旧鬼門テーマで型だけ使う (D-014 で却下済)
