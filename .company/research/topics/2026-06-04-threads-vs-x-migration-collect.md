# Threads vs X 移行 リサーチ (2026-06-04)

## サマリ
- 2026 年 1 月の Similarweb 集計で、**モバイル日次アクティブが Threads 1.415 億 / X 1.262 億**と逆転。9 月の僅差から「明確な差」に拡大した。
- 一方 Web は **X 1.4540 億 / Threads 850 万**で依然 X 圧勝。スマホ生活者の取り合いだけ Threads が勝っている状態。
- MAU は Meta 公式で **Threads 4 億超**（2025-08 ザッカーバーグ発表）、X はサードパーティ集計で 5.5 億前後。前年比は **Threads +38% / X DAU -11.9%**。
- 移行の引き金は (a) X の Grok ヌード生成問題に対する各国の取り締まり (b) アルゴリズムやモデレーションへの不信感 (c) 有料化/サ終懸念。
- 旧 Twitter のパワーユーザー（週 10 投稿以上）**39% が Threads か Bluesky を併用**しているという調査もある。
- 日本市場では Threads MAU 約 **1,500 万 / 前年比 +114%**。主要 SNS の中で伸び率トップ。
