### 【一次情報】Claude Code 週次ダイジェスト（公式）
- ソース: https://code.claude.com/docs/ja/whats-new
- 公開日: 2026-05-08（最新Week 19）
- 要点（3行）:
  - Week 19（5/4-8, v2.1.128-136）: プラグインが `.zip` / URL から読み込めるように。`--plugin-dir`(.zip)・`--plugin-url`。`worktree.baseRef` 追加。auto mode の hard deny ルール追加。hooks が `effort.level` を確認可能に。

  - 切り口②: 「`/ultrareview` 知ってる？クラウドにバグ検出エージェントの**フリート**を投げて、結果が CLI に戻ってくる。自分のコードに『軍隊』をぶつける時代」
  - 切り口③: 「Claude Code の v2.1.128 から、プラグインが `.zip` と URL で配れるようになった。これ、**スキル流通市場**が立つ前夜」

## 3. Threads アルゴリズム / 運用

### Threads アルゴリズム 2026 完全攻略
- ソース: https://addness.co.jp/media/threads-algorithms/
- 公開日: 2026年最新（推定 5月初旬）
- 要点（3行）:
  - **リプライは「いいね」の約10倍の評価**。会話の盛り上がり＝最重要シグナル。
  - **投稿後30〜45分の初速**が、その後のレコメンド到達を決める。
  - トピックタグは1つに絞る／500字以内で「ツッコミ代」を残す／リプライのリプライまで返す。1日1〜3投稿、最低週3。
- 投稿アイデア:
  - 型: 教育目的
  - 切り口①: 「Threads でリプライ1件 ≒ いいね10件。**いいねを集める設計を捨てて、ツッコまれる設計に振る**だけで伸び方が変わる」
  - 切り口②: 「投稿後30分の初速が全部決める。だから**投稿時間より、投稿直後に自分が反応できる時間か**のほうが大事。深夜投稿が爆発しない理由はこれ」
  - 切り口③: 「500字フルで書くと負ける。**ツッコミ代を残した400字**の方が伸びる、を1ヶ月検証した話」
