### 個人開発はオワコンなのか？2026年に感じた現実 (Qiita)
- ソース: https://qiita.com/elliot_james/items/1c29989205b0c998c9ff
- 公開日: 2026-06-03
- 要点（3行以内）:
  - 「オワコンではない、ただし昔より難しくなった」が筆者の結論。AI で参入障壁が崩れ、自動的に売れる時代は終わった。
  - 重要なのは 4 つ: 開発スピード / マーケ / ユーザー対話 / 継続力。「作る力」より「届ける力」。
  - 「数ヶ月で更新が止まる個人開発が多い → 続けるだけで上位」と継続を競争優位として強調。
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育目的 (信頼構築)
  - 切り口: 「個人開発オワコン論への自分の答え。AI時代に残るのは "作る力" じゃなくて "届ける力" だけ。実際自分も〜だった」
  - 補足: gaku の実体験 (note 0円・60日で月10万ロードマップ) と完全に同じ温度感。深く頷ける一次体験として書ける。

### Claude Code で副業フリーランス3ヶ月 / 受注14万円・失敗5回 (Zenn)
- ソース: https://zenn.dev/katakanaonline/articles/claude-code-freelance-3months
- 公開日: 2026-04-01
- 要点（3行以内）:
  - 本業エンジニアが Claude Code 副業で3ヶ月¥140,000受注。総労働 54h、時給換算¥2,600。
  - Upwork 163件応募で返信7件(4.3%) → ココナラ/ランサーズに転換。Zapier→n8n 移行案件は15h溶かして成果ゼロ。
  - 救世主は「CLAUDE.md を法律として扱う」。AI が勝手にクライアントへメッセージ送信した事件後、外部アクション禁止ルール化で激減。
- 投稿アイデア:
  - 型: 夕失敗型 / 教育目的
  - 切り口: 「Claude Code で副業始めた人が3ヶ月で14万受注した話、Upwork は 163 件中 7 件しか返信なくて結局国内案件サイトに逃げた、というデータが生々しい」
  - 補足: "AI が勝手にメッセージ送った" の固有エピソードがフック。gaku 自身も Discord Bot で AI に任せる範囲を議論しているので親和性◎。

### Claude code で月3万→月15万 (note)
- ソース: https://note.com/happy_recipes/n/neea55b001b3c
- 公開日: 2026-01-03
- 要点（3行以内）:
  - MVP までの想定: 準備1-2週間 → 開発2-4週間 → 月額500-1500円で月3万 → ユーザーFB反映で月10-15万。
  - 成功例として "Instagram キャプション生成ツール / 猫写真整理 / 家計簿" を例示。月額サブスク前提。
  - 初収益¥3,500 (リリース2週間後) → 初月¥28,000 → スケール期で10倍化、という具体数字が出てる。
- 投稿アイデア:
  - 型: 朝学び型 / 販売 (gaku の月10万ロードマップと地続き)
  - 切り口: 「月3万→月15万って "ユーザーFBを反映する2ヶ月目" が分岐点らしい。リリースして満足してる人ほどここで止まる」
  - 補足: gaku のロードマップは2026-07-13期限。この記事の「2ヶ月で5倍」の現実味は自分の経験と照らして語れる。

### 個人開発×Vibe Coding 月2,000円 (Zenn, 2025-06)

### バイブコーディング 2026年最新ガイド (ShiftB)
