## ① 実績づくり完全マニュアル

### 核心: 実績は2種類ある

| 種類 | 定義 | 特徴 |
|------|------|------|
| **数字の実績** | 5kg痩せた / 2万円稼いだ / 1万円節約 | 結果が出なかったら使えない |
| **努力実績** | 調べた数・試した数・継続した数 | やったこと全てが価値になる。否定されない |

**ぼくへの示唆**: ぼくには「202本投稿した」「140本を全数分析した」「Threadsで月1万稼ぐ人100件分析した」がある。これが努力実績として使える。

---

### 実績の作り方 ①：今ある経験を変換する

自己棚卸し3問：
- 今の仕事・生活で毎日当たり前にやっていることは？
- 人から「すごいね」「どうやってるの？」と言われたことは？
- 過去に乗り越えた困難や解決した悩みは？

→「当たり前のこと」が知らない人には有料情報。

---

### 実績の作り方 ②：自分で実践して数字で記録

**3ステップ:**
1. noteに書こうと思っているノウハウをまず自分で実践する
2. 始める「前」の数字をスクショ（一番大事）
3. 1週間〜1ヶ月やってみる → 変化を記録

**例:**
- 食費4.2万→2.8万 → 「1ヶ月で食費1.4万削減した方法」
- 体重58kg→55kg → 「3ヶ月で3キロ落とした主婦のリアルダイエット記録」

スクショ1枚がどんな言葉より説得力を持つ。

---

### 実績の作り方 ③：徹底リサーチで「調べた実績」を作る（努力実績）

体験ゼロでも「リサーチの量と整理力が実績になる」。

**例:**
- 「人気の家計簿アプリ30個を全部使って比較してみた」
- 「Amazon評価4.5以上のダイエット本を20冊読んで共通点をまとめた」
- **「Threadsで月1万円以上稼いでいる人の投稿を100件分析してわかったこと」** ← ぼくに直接使える

リサーチ系noteは：自分の知識も深まる → Threads発信ネタにもなる → 次のnoteの土台にもなる（一石三鳥）。

---

### 番外編：寄生型ビジネス（アフィリエイト）

実績も商品もゼロでも売上が作れる。すでに売れている人の商品を紹介して利益の半分を得る。
**注意点:** 「誰の商品に寄生するか」の見極めが最重要。勢いと信用がある人の商品に乗る。

---

### noteテーマ発掘 10の質問シート

```
Q1. 1年前のあなたが一番悩んでいたことは？
Q2. その悩み、今は解決できていますか？（少しでも改善したならOK）
Q3. その悩みを解決するために、具体的に何をしましたか？
Q4. 友達や家族から「教えて！」「それどうやったの？」と聞かれることはある？
Q5. SNSやネットで「自分の方がうまく説明できるのに…」と思ったことは？
Q6. これまでにお金を払ってでも解決したかった悩みは？
Q7. 「あの頃の自分に教えてあげたい！」と思うことは？
Q8. 趣味や好きなことで、人よりちょっと詳しいことは？
Q9. 「これ知らない人、損してるな…」と思う情報やコツは？
Q10. ここまで書いた中で「これなら私でも書けそう！」と一番思えたのはどれ？
```
→ Q10で選んだものがnoteのテーマ。

**大事なこと:** noteに必要なのは「すごい実績があること」ではなく「同じ悩みを持ってた人がリアルに語ること」。

## ② note制作プロンプト集（Ponyo版）

### ❶ Deep Researchプロンプト

```
note（note.com）で現在売れている有料記事を実際に調べて、副業初心者が書ける有料noteの企画案を作ってください。

■ STEP1：市場調査
note.comで実際に売れている有料記事を調べて、以下を特定してください。
・人気ジャンル（美容、副業、恋愛、健康、仕事術、人間関係、お金、メンタルなど）
・各ジャンルで売れている記事のタイトルの傾向と価格帯
・特に「個人の実体験ベース」で、資格や専門知識がなくても書ける記事に絞ること

■ STEP2：競合分析＆差別化ポイントの発見
STEP1で見つけた各ジャンルについて、以下を分析してください。
・競合がすでに出している記事のタイトル・切り口の傾向
・読者（購入者）がどんな悩みや欲求を抱えて購入しているか
・競合がまだカバーできていない「空白の切り口」や「ずらしポイント」

■ STEP3：企画案の提案（5つ）
以上をもとに、初心者が今すぐ書ける有料noteの企画案を5つ、以下のフォーマットで提案してください。
【テーマ】どのジャンル・話題か
【タイトル案】競合と被らず、読者が「これ私に必要だ」と感じるタイトル（売れ筋を参考にしつつ、切り口を少しずらしたもの）
【ターゲット読者】具体的にどんな人が買うか（年代・状況・悩み）
【コンセプト】この記事の「売り」は何か。他の記事とどう違うのか。読者が読んだ後にどう変われるか
【推奨価格】そのジャンルの相場を踏まえた価格帯

※重要な条件：専門資格・特別なスキル不要で、自分の日常の体験や工夫だけで書けるテーマに限定すること

💡 ChatGPTの「Deep Research」モードに切り替えてから投げてください
```

### ❷ 構成作成プロンプト

```
先ほどの企画案の中から【○○】を採用します。
この企画で有料noteを作りたいので、「読者がお金を払ってでも読みたい！」と感じる記事の構成（目次）を作ってください。

以下の条件を満たしてください：
・各章のタイトルは、読者が「この章だけでも読みたい」と思うようなコピーにすること
・無料で読める部分（冒頭〜序盤）と有料部分（中盤以降）の区切りを明確にすること
・読者が読み終わった後に「すぐ行動できる」実践的な構成にすること
・全体で5,000〜10,000文字程度を想定した章立てにすること

💡 【○○】の部分を、❶で出てきた企画案の中から選んだテーマに書き換えてください
```

### ❸ 無料パート執筆プロンプト

```
以下の目次の無料パート（第○章〜第○章）の本文を書いてください。
この部分の目的は、読者に"この先も読みたい！お金を払ってでも続きが知りたい！"と思わせることです。

以下の条件で書いてください：
・冒頭で読者の悩みに強く共感すること
・"この記事を読めば解決できる"という期待感を持たせること
・具体的な数字や実体験を入れてリアリティを出すこと
・有料パートの手前で"一番気になるポイント"を予告して、続きへの期待を最大化すること
・無料部分のラスト、有料部分に切り替わる直前に、有料パートを絶対に読みたくなるように、それ以降の有料パートの目次を書いて。続きはこんな感じです、気になるでしょ？って思わせることが目的です。この有料パートの目次にはコピーライティングを使ってください

※ここに先ほどの構成・目次をコピペする

💡 ❷で作った構成・目次をプロンプトの最後にコピペしてから投げてください
```

### ❹ 有料パート執筆プロンプト（章ごとに使う）

```
第○章「○○○○○○○○」の本文を書いてください。
この章は有料パートです。お金を払って読んでくれた読者が"この章だけでも元が取れた"と感じるくらい、価値の高い内容にしてください。

以下の条件で書いてください：
・読者は○○で悩んでいる初心者
・具体的なやり方やステップを、すぐ実践できるレベルで詳しく書くこと
・数字や実例を交えて説得力のある内容にすること
・読者が読み終わった後に「次の章も読みたい」と思える流れにすること

## ③ Threads投稿ネタ出しプロンプト（Ponyo版）

### 投稿バランスの目安
- 日常ポスト：3割
- 教育ポスト：5割
- セールスポスト：1〜2割

---

### 日常ポスト ネタ出しプロンプト

「この人、親しみやすいな」と思ってもらうための投稿。すごいことを書く必要なし。

```
あなたはThreadsで「○○（テーマ）」をテーマに発信しているアカウントの運用アドバイザーです。
以下の条件で、フォロワーとの距離が縮まるような「日常ポスト」のネタを10個考えてください。

【発信テーマ】○○
【ターゲット】○○に悩んでいる人（例：貯金できない主婦、副業初心者のサラリーマン）
【私のキャラクター】○○（例：元カツカツ主婦、脱サラした会社員）

条件：
・テーマに関連した日常の小さな出来事や気づきの投稿にすること
・読者が思わずコメントしたくなるような「問いかけ」や「あるあるネタ」を入れること
・上から目線やイキった表現は絶対にNG。親しみやすく、距離が近い文体で
・絵文字は1〜2個まで。使いすぎない
・1投稿あたり100〜200文字くらいのカジュアルな長さで
・実際にそのまま投稿できるレベルの文章で出力すること
```

**ぼくの入力例:**
```
【発信テーマ】AI副業・Threads運用実験記
【ターゲット】副業で0円が続いている30代サラリーマン
【私のキャラクター】3ヶ月202本投稿してまだ0円の会社員
```

---

### 教育ポスト ネタ出しプロンプト

読者の価値観をじわじわ変えてnoteを「欲しい！」と思わせる投稿。

```
あなたはThreadsで「○○○」をテーマに発信しているアカウントの運用アドバイザーです。
以下の3つの型で、教育ポストのネタをそれぞれ5個ずつ（合計15個）考えてください。

【発信テーマ】○○
【ターゲット】○○に悩んでいる人
【私のキャラクター】○○
【販売しているnoteの内容】○○（例：月3万円貯金できるようになる節約術）

■ 型1：理想の状態を見せるポスト（5個）
→ 自分がその方法で成果やメリットを得ている様子を見せる投稿
→ 読んだ人が「え、私もやりたい！」「いいな！」と思うもの

■ 型2：恐怖を煽るポスト（5個）
→ 「知らないと損してる」「やらないとヤバい」と気づかせる投稿
→ 「この人の発信ちゃんとチェックしておかなきゃ」と思わせるもの

■ 型3：共感ポスト（5個）
→ 自分の過去の失敗や苦労を語ったり、理念を語る投稿
→ 「この人の過去、私と同じだ…」と共感してファンになってもらうもの

条件：
・上から目線の「教えてあげる」感は絶対にNG
・あくまで自分の体験ベースで、同じ目線から語る
・Threadsの文化に合った、自然体でカジュアルな文体
・1投稿あたり150〜300文字くらい
・実際にそのまま投稿できるレベルの文章で出力すること
```

---

### セールスポスト ネタ出しプロンプト

noteを売り込まずに自然に誘導する。「買ってください！」は絶対NG。

```
あなたはThreadsで「○○（テーマ）」をテーマに発信しているアカウントの運用アドバイザーです。
以下の条件で、売り込み感を出さずに自然にnoteへ誘導する「セールスポスト」のネタを7個考えてください。

【発信テーマ】○○
【ターゲット】○○に悩んでいる人
【私のキャラクター】○○
【販売しているnoteのタイトル】○○
【noteの内容（ざっくり）】○○

条件：
・「note買ってください！」のような露骨なセールスは絶対NG
・以下のパターンを使い分けて作成すること：
  パターンA：読者の悩みに寄り添う→「実はその解決方法、noteにまとめました」
  パターンB：自分の体験を語る→「詳しくはプロフィールのリンクから」
  パターンC：読者の成果報告を紹介→「この方法をまとめたnoteはプロフにあります」
  パターンD：noteの一部を無料チラ見せ→「続きはnoteで書いてます」
・上から目線にならず、あくまで「困ってる人のお役に立てれば」のスタンス
・Threadsの文化に合った、距離が近くてカジュアルな文体
・1投稿あたり150〜250文字くらい
・実際にそのまま投稿できるレベルの文章で出力すること
```

**ネタ補充の追加プロンプト:**
```
さっきとは違う切り口で、もう10個ネタを考えて。前回と内容が被らないようにして！
```
または
```
今度は「○○な季節」「○○なイベント」に合わせたネタで10個お願い！
```

## ④ 購入率5倍プロンプト（無料部分仕上げ）

有料パートの目次をコピーライティング×虫食い形式に変換する最後の仕上げ。

### 使い方 5ステップ
1. noteを完成させる（有料パートの目次ができている状態）
2. 有料パートの目次をコピーする
3. 下のプロンプトに貼り付けてAIに投げる
4. AIが「コピーライティング×虫食い」に変換してくれる
5. それを無料パートの最後にペーストして完成

### プロンプト（コピペで即使用可）

```
あなたはコピーライティングのプロフェッショナルです。
これから、私のnote記事の「有料パート」の目次を渡します。
この目次を、無料パートの一番最後に「有料パートの予告」として貼りたいです。
読者が目次を見ただけで「え、これ気になる…続き読みたい…！」と
思わず有料パートを購入したくなるように、以下の2つの加工をしてください。

━━━━━━━━━━━━━━━━━━━━
【加工① コピーライティング化】
━━━━━━━━━━━━━━━━━━━━
各章のタイトルを、以下のテクニックを使って書き換えてください：
・読者が「この章だけでも読みたい！」と思う好奇心を刺激する表現にする
・「え、そんなことまで教えてくれるの？」と驚かせる
・具体的な数字やベネフィットを盛り込む
・ありきたりな表現ではなく、思わず目が止まるコピーにする

━━━━━━━━━━━━━━━━━━━━
【加工② 虫食い（穴あき）化】
━━━━━━━━━━━━━━━━━━━━
加工①で書き換えたタイトルの中から、
最も核心的な部分（具体的なノウハウ名・数字・方法論）を
「●●●」で伏せてください。

虫食いのルール：
・全体の3〜5割の章に虫食いを入れる（全部に入れない）
・「何の話かはわかるけど、肝心の答えだけが見えない」状態にする
・伏せる箇所は1つの章につき1〜2ワードだけ（伏せすぎない）
・虫食いにしない章も、コピーライティングは効かせたまま残す

━━━━━━━━━━━━━━━━━━━━
【出力形式】
━━━━━━━━━━━━━━━━━━━━
noteの無料パートの最後にそのまま貼れる形式で出力してください：
1. 冒頭に、読者の期待感を煽る導入文を1〜2行つける
   （例：「▼ここから先の有料パートでは、こんな内容を解説しています」）
2. 各章を箇条書きで並べる
3. 最後に、購入を後押しする一言を添える
   （例：「気になる章が1つでもあったら、ぜひ続きを読んでみてください」）

━━━━━━━━━━━━━━━━━━━━
【私の記事情報】
━━━━━━━━━━━━━━━━━━━━
■ 記事のジャンル：【ここに入力 → 例：副業、美容、恋愛、投資、ダイエット】
■ 想定読者：【ここに入力 → 例：副業初心者の20〜30代女性】
■ 記事の価格帯：【ここに入力 → 例：980円、1,980円、2,980円】

━━━━━━━━━━━━━━━━━━━━
【有料パートの目次】
━━━━━━━━━━━━━━━━━━━━
（ここにあなたのnoteの有料パートの目次をそのまま貼り付ける）
```

## ⑤ AIプロフィールアイコン作成プロンプト

ChatGPT（DALL-E）またはGeminiに投げる。

```
以下の条件で、SNS（note）用のプロフィールアイコン画像を1枚生成してください。

■ 発信ジャンル：【ここに入力 → 例：副業、美容、料理、投資、子育て、恋愛、ダイエット】
■ 性別：【男性 / 女性 / 指定なし → どれか1つ選ぶ】
■ 年代のイメージ：【20代 / 30代 / 40代 / 年齢感なし → どれか1つ選ぶ】
■ 雰囲気：【ここに入力 → 例：やさしい、クール、知的、ポップ、ナチュラル、高級感、元気】
■ 服装のイメージ：【ここに入力 → 例：カジュアル、オフィスカジュアル、パーカー、きれいめ、おまかせ】
■ 画像スタイル：【① アニメ風 / ② 実写風 / ③ イラスト風 → どれか1つ選ぶ】
■ 背景：【上で選んだ画像スタイルに合わせて以下から選ぶ】

＜①アニメ風＞
A. 淡いグラデーション（きれいめ・万能）
B. 光が差し込む白背景（シンプル・洗練）
C. 控えめな幾何学模様（スタイリッシュ）
D. ジャンルに関連する小さなアイコンがうっすら散りばめられた背景（個性的）

＜②実写風＞
A. やわらかくぼかした丸い光の玉（ボケ）が浮かぶ背景（おしゃれ・プロっぽい）
