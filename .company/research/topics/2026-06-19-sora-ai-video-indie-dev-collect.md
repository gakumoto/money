# Sora AI 動画生成 × 個人開発 リサーチ (2026-06-19)

## エグゼクティブサマリ

**最重要トピック: Sora 2 API は 2026-09-24 にシャットダウン**。
2026-03-24 にOpenAI が正式発表。consumer アプリは 2026-04-26 終了済み、API は残り約3ヶ月。
個人開発で Sora 依存サービスを作っているなら今すぐ Veo 3 / Kling 3.0 / Runway Gen-4.5 / Luma などへ移行が必要。
「単一API依存で詰んだ個人開発者」のリアルが投稿になる旬な題材。

### Sora 2 API シャットダウン正式発表 (2026-03-24)
- ソース: https://www.ai.cc/blogs/openai-sora-shutdown-best-ai-video-generation-api-alternatives-2026-migration-guide/
- ソース: https://morphed.app/blog/sora-ai-video-generator
- 公開日: 2026-03-24 (発表) / 2026-04-26 (アプリ終了) / 2026-09-24 (API終了)
- 要点（3行以内）:
  - OpenAI が Sora 撤退を正式発表。理由は1日100万ドル運用コスト + アクティブユーザーが100万 → 50万に半減。
  - Disney との 10億ドル equity 契約も同時に解消。著作権・安全性プレッシャーも撤退要因。
  - 移行推奨期限は 2026-09-01。サードパーティ proxy API も同日に死ぬ。
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育・思考目的
  - 切り口: 「1日1億円赤字で消えた Sora。個人開発で『1社のAPIに全部賭ける』ことの本当の怖さ」

### Sora 2 API 料金体系 (2026年版)
- ソース: https://romptn.com/article/78277
- 公開日: 2026年最新
- 要点（3行以内）:
  - 標準モデル: $0.10/秒・720p。12秒で約180円(1ドル=150円換算)。
  - Pro モデル: 720pで$0.30/秒、1024×1792で$0.50/秒。12秒で約900円。
  - 利用には API キー + 最低$5チャージ(Tier 1) + 顔写真本人確認(最大15分)。手軽さは皆無。
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「Sora 2 API を実際に叩いてみたら『1動画100円』。これは個人開発に組み込めるラインか試算した」

### Sora 2 で稼ぐ 3つの型 + 5つのアイデア
- ソース: https://note.com/yu_inamori/n/n9c765f090483
- 公開日: 2026年
- 要点（3行以内）:
  - 3型: ①インフルエンサー型(YouTubeショート/SNS) ②販売型(素材・プロンプト集) ③受注型(クラウドワークス・ココナラ)。
  - 受注型が最速で収益化。ココナラの感動ムービー制作は1件 5,000〜50,000円。
  - 「Adobe Stock に素材出品」は低難易度・自動収益型だが、登録審査がボトルネック。
- 投稿アイデア:
  - 型: 夕失敗共有型 or 朝学び型 / 信頼構築目的
  - 切り口: 「Sora で稼ぐ系の note を5本まとめ読みして、現実的に個人ができるのは結局この3つだった」
