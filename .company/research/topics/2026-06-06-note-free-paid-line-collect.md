## 1. note 公式の30万件分析データ (一次情報)

### 30万件の有料記事を分析、初心者でも収益化しやすいテーマが判明
- ソース: https://prtimes.jp/main/html/rd/p/000000360.000017890.html
- 関連: https://note.jp/n/n8522197d1ced
- 公開日: 2025年12月 (2026-06-06時点で最新の公式分析)
- 要点:
  - 実用ノウハウ系の平均単価 **1,842円**、読み物系 **983円** (約1.9倍差)
  - **文字数と売上に相関なし** (実用-0.023 / 読み物0.011) → 「長く書く=売れる」は嘘
  - 育児カテゴリのメンバーシップ売上トップ10のうち **7人が1年以内の新規参入** → 新規でも勝てる
  - 急上昇は2系統: ①「テクノロジー・AI活用 / SNS運用 / 複業・在宅ワーク」 ②「育児・教育」
  - メンバーシップ売上 +81.3% (前年同月比/2025-11)、有料記事売上 +26.8%
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「note公式が30万件分析した結果『文字数と売上は相関ゼロ』だった話」
  - 切り口2: 「実用1,842円 / 読み物983円 — note平均単価の差が"売れる文章設計"を決める」

## 2. 価格帯別 購入率データ (100/500/980円の現実)

### 有料noteの「価格設定」に迷う初心者へ ｜ 100円・500円・980円
- ソース: https://note.com/freelife_creator/n/n322a6e598d0b
- 公開日: 2025年〜2026年初頭
- 要点:
  - **100円**: 購入率 5〜10% / 月1000PVなら ¥5,000
  - **500円**: 購入率 1〜2% / 月1000PVなら ¥7,500 (バランス最強)
  - **980円**: 購入率 0.5%以下 / 月1000PVなら ¥4,900
  - 結論: 売上トータルでは **500円が最も伸びる** 中央値ゾーン
  - 100円は「安さがブランドを毀損」する両刃の剣
- 投稿アイデア:
  - 型: 夜振り返り / 教育目的
  - 切り口: 「note 100円は買われるけど儲からない — 500円が"勝ち値段"の理由をデータで」
  - 切り口2: 「『980円高すぎ問題』は嘘 — 月1000PVで100円より儲かる根拠」

### note公式が出した「売れている記事の平均価格」

## 3. 無料部分 / 有料部分の "切る場所" 設計

### 売れるnoteはここで決まる — 無料部分と有料部分の正しい分け方
- ソース: https://note.com/firm_rabbit1903/n/n0e815a15b099
- 関連: https://note.com/ai_hitsujisan/n/n364f6324556e (黄金バランス)
- 関連: https://note.com/natsuo_money/n/nf0a688dd17cc (無料エリア文字数)
- 要点:
  - **70%無料 / 30%有料** が黄金比 (満足感と購入動機の両立)
  - 無料エリア最適文字数 **3,500〜4,000字** (「腹七分目」感)
  - 無料: 問題提起 + 共感 + 価値ヒント1つ
  - 有料: 「無料で立てた問い」に対する **再現性ある手順** で答える
  - 切る場所のNG: 無料部分で「結論ぜんぶ言う」 or 「価値ヒント0で予告だけ」
- 投稿アイデア:
  - 型: 昼進捗 / 教育目的
  - 切り口: 「note 無料部分は3,500字 — 多いと買われない、少ないと信用されない」
  - 切り口2: 「70:30の黄金比 — 有料記事が"短くてもいい"理由」

### 無料記事ゼロでもnote有料記事が売れるコツ
- ソース: https://note.com/naoto1014aaa/n/ne27668940d03
- 要点:
  - 無料記事を量産しなくても、**SNS (Threads/X) を無料部分の代替**にできる
  - SNSで「問題提起 + 共感 + 価値ヒント1つ」を蓄積 → note は最初から有料で出す
  - 注意: フォロワーとの信頼資産が前提 (ゼロからやるとコケる)
- 投稿アイデア:
  - 型: 夜振り返り / 信頼構築
  - 切り口: 「Threads が"note の無料部分"だと気づいてから、月収が変わった」
