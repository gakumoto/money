# Threads vs X 移行 — 2026-06-19 収集

## 背景
ユーザー指定テーマ「Threads vs X 移行」。脱X→Threadsの動きが2026年1月時点でモバイル日次アクティブで逆転した。gaku の「Threads × note 月10万」ロードマップにダイレクトに刺さるネタとして投稿転用可能。

---

## 収集情報

### 1. Threads、モバイル日次アクティブで初めて Xを抜く（2026年1月）
- ソース: https://www.gizmodo.jp/2026/01/threads-is-now-clearly-more-popular-than-x.html
- 公開日: 2026-01
- 要点（3行）:
  - モバイルアプリ日次アクティブ: Threads 1億4,150万 vs X 1億2,500万（Threads逆転）
  - ただしブラウザ利用は X.com 1億4,070万 / Threads.com 770万で X が圧勝
  - 脱X加速の背景に Grok の画像悪用問題＋各国規制強化
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「2026年1月、Threadsがついに Xをモバイルで抜いた。でもブラウザはまだ X が18倍強い。何が言えるかというと、Threads は『スマホで1日に何回も開かれる場所』になったってこと」

### 2. Threadsは Xより73%エンゲージメント率が高い
- ソース: https://www.imarkinfotech.com/threads-marketing-strategy-2026-why-threads-just-overtook-x-in-active-user-growth/
- 公開日: 2026
- 要点（3行）:
  - Threads の中央値エンゲージメント率 6.25% / X は 3.6%
  - Threads は 400M MAU を 2.5年で達成、X は 600M に17年かかった
  - 成長速度の桁が違うフェーズに入っている
- 投稿アイデア:
  - 型: 昼進捗型 / 教育目的
  - 切り口: 「Xでフォロワー1万でやっと反応が出るのが、Threadsだと300人で同じくらい来る理由。エンゲージメント率が約2倍違うってデータがある」

### 3. Threadsアルゴリズム「3つの鍵」と「4つの評価ステージ」
- ソース: https://addness.co.jp/media/threads-algorithms/
- 公開日: 2026
- 要点（3行）:
  - 3つの鍵: ①投稿頻度（毎日1本以上） ②会話の質（返信が命） ③テキスト中心
  - 4ステージ: 初期(一部フォロワー)→拡散(全フォロワー)→発見(非フォロワー)→広範囲
  - X = 速さとリポスト勝負 / Threads = 会話の深さと持続性
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「X時代の癖が抜けない人がやりがちな失敗。『投稿して終わり』じゃ伸びない。Threadsは返信ついてからが勝負ってMeta公式が言ってる」

### 4. Threadsの「オーディエンス・インサイト」拡充
- ソース: https://www.musically.jp/threads-creator-insights
- 公開日: 2025 (7/23 提供開始)
- 要点（3行）:
  - 都市/国/年齢/性別のデモグラ分析
  - 過去7〜90日の反応上位ランキング表示
  - Instagram/Facebookからの外部流入元も分かる
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育目的
  - 切り口: 「Threadsのインサイト見て初めて気づいた。自分が想定してた読者層と、実際に反応くれてた人が全然違ってた件」

### 5. Threads × note 連携が「現在の最強戦略」と言われる理由
- ソース: https://note.com/tothinks/n/na7058f995306
- 公開日: 2026
- 要点（3行）:
  - Threads = 拡散力, note = 長文での収益化、役割分担で生態系を作る
  - 「フォロワー300人で月10万」の事例が紹介されている（※煽り気味のため鵜呑み厳禁）
  - Meta はサブスク・投げ銭の収益機能を予告だが2026年3月時点で時期未定
- 投稿アイデア:
  - 型: 営業型 / 販売目的
  - 切り口: 「Threadsだけで稼ごうとして失敗した話。note 0円のまま3週間で気づいたこと。フォロワー集めだけじゃ意味なくて、深い話を置く場所がいる」（自分のnote導線にそのまま接続）

### 6. 2026年は「Threads参入の最後の先行者利益タイミング」論
- ソース: https://mangaiti.com/threads-growth-2026/
- 公開日: 2026
- 要点（3行）:
  - 日本国内 Threads ユーザー 170万人、過去2年で約4倍
  - 企業参入がまだ少なく、個人クリエイターに先行者利益が残っている
  - Instagram 連携で既存フォロワーから拡散できる構造的強み
- 投稿アイデア:
  - 型: 深夜思考型 / 信頼構築目的
  - 切り口: 「2年前にThreads始めた人と、今始める人で、たぶん同じくらいのチャンスがある。企業がまだ来てないSNSってあと何年残るんだろう」
