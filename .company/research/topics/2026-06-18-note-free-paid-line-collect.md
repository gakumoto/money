## 背景
gaku 自身が note 課金導線(980円1本確定)を稼働させた直後。

## 1. note公式：30万件分析プレスリリース
- ソース: https://prtimes.jp/main/html/rd/p/000000360.000017890.html
- 公開日: 2026-01-07
- 要点:
  - 約30万件の有料記事 (2024-12〜2025-11) を分析した公式リリース
  - 急成長テーマ: **テクノロジー・AI活用 / SNS運用 / 複業・在宅ワーク**
  - 売上前年同月比: **有料記事 +26.8% / メンバーシップ +81.3%**
  - 実用ノウハウ系平均価格 **1,842円** / 読み物系 **983円** (約1.9倍差)
  - メンバーシップ売上トップ10中 **7人が1年以内の新規参入者** (育児・教育)
  - **「文字数と売上に相関なし」「その人にしか語れない経験」が価値**
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「note公式が30万件分析してた。"文字数じゃない、自分にしか書けないかどうか" って結論。」

## 2. しおどめ氏：実用1800円・読み物980円の根拠 (公式データ解釈)
- ソース: https://note.com/shiodome_098/n/ncaaed7795642
- 公開日: 2026年 (公式30万件データ受け解釈)
- 要点:
  - 実用系トップ20%は **1,800円帯**、読み物系トップ20%は **980円帯**
  - 実用系を980→1800円に変えると **収益約1.8倍** の可能性
  - 実用系=ROIが計算できる/繰り返し参照=高価格許容
  - 読み物系=感情価値=ROI計算困難=980円が事実上の上限
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「ROIを計算できる記事は1800円までイケる。エッセイは980円で止まる。価格の天井は "再読されるか" で決まる。」

## 4. かける氏：100円/500円/980円どれで始めるべきか
- ソース: https://note.com/freelife_creator/n/n322a6e598d0b
- 公開日: 2026年最新
- 要点:
  - **初投稿は300円テスト** が推奨 (失敗しても許せる金額/購入ハードル最小)

- 投稿アイデア:
  - 型: 夕失敗 / 教育目的

  - ※gaku の現状: 980円1本 — 「最初は怖かったけど 980 にした理由」を逆張りで書ける

## 5. しーん氏：無料→有料の切り替えタイミング (体験談)
- ソース: https://note.com/siin_de_note51/n/nf492089f0edc
- 公開日: 2026年
- 要点:
  - **「解決の一歩手前」で区切る** — 読者が一番知りたい部分の直前で無料終了
  - 無料は「基本情報 1〜2個まで」、有料は「具体的手順 / テンプレ / ミス回避策」
  - 「ここまで無料でいいの？」と思わせられたら成功の目安
  - 「無料部分だけでも十分学べた、迷わず買った」コメントが売上につながる
- 投稿アイデア:
  - 型: 夜振り返り / 教育目的
  - 切り口: 「note の有料ライン、"解決の一歩手前" で切る。"答えの直前で扉を閉める" イメージ。」

## 6. たくま氏：売れる構成5つの型
- ソース: https://note.com/takuma_signal/n/n60eb47a4c1c4
- 公開日: 2026年
- 要点:

## 7. note公式ヘルプ：有料ラインの仕様 (運用知識)

  - 切り口: 「有料 note、出した後でも価格・ライン位置を全部後から動かせる。"完璧に決めてから出す" 必要ゼロ。」

## 8. note収益化の SNS 流入構造
- ソース: https://www.sungrove.co.jp/note-paid-article/ / 複数記事の合意
- 公開日: 2026年
- 要点:
  - note 読者の **約70%が SNS 経由**
  - SNS 発信なしで売上を伸ばすのは事実上困難
- 投稿アイデア:
  - 型: 夜振り返り / 信頼構築
  - 切り口: 「note の読者の7割は SNS 経由で来る。"いい記事書けば売れる" じゃなくて "Threads がエンジンで note がレジ" の構造。」
