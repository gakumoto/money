## 調査内容

### Threads ランキングシグナルの「3 + 2」構造
- ソース: https://addness.co.jp/media/threads-algorithms/
- ソース: https://posteverywhere.ai/blog/how-the-threads-algorithm-works
- ソース: https://miraflow.ai/blog/threads-algorithm-2026-how-to-grow-meta-text-platform
- 公開日: 2026-02-25 / 2026-03-16
- 要点（3行以内）:
  - 表に出てる「伸びる3つの鍵」: ①投稿頻度（週2〜5 / 理想は1日1回以上）②会話の質（リプライ > いいね）③テキスト中心（AI が文脈を理解できる）
  - 内部の AI シグナルは 5 種類: いいね予測 / リプライ CTR / フォロー確率 / プロフィールクリック率 / スクロール挙動（滞在時間）
  - ハッシュタグの効果は薄れ、トピックタグは 1 つに絞ったほうが配信精度が上がる
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「Threads のアルゴリズムが見てるシグナル、5 つ。スクロール挙動まで読まれてる。だから『止まって読ませる1行』が全部の起点になる」

### 会話velocity（初速45分が勝負）
- ソース: https://note.com/takeru_biz/n/n4e9e5b5d886d
- ソース: https://miraflow.ai/blog/threads-algorithm-2026-how-to-grow-meta-text-platform
- 公開日: 2026-03-25 / 2026-03-16
- 要点（3行以内）:
  - 「30 分で 20 リプライ」のほうが「24 時間で 50 リプライ」より積極配信される
  - 投稿後 30〜45 分でレコメンド掲載が決まる。投稿者自身が即返信してラリーを延ばすのが効く
  - 「いいね 100 / 返信 0」より「いいね 30 / 返信 20」のほうが伸びる
- 投稿アイデア:
  - 型: 夕失敗型 / 教育目的
  - 切り口: 「Threads、投稿してから 45 分で勝負ついてる。寝る前に投げて寝る運用、いちばん損してる。ぼくも今やめた」

### 4 つの評価ステージ（配信が広がる順序）
- ソース: https://addness.co.jp/media/threads-algorithms/
- 公開日: 2026-02-25
- 要点（3行以内）:
  - Stage1: フォロワーの一部に配信 → 初速の反応で次が決まる（投稿後1時間は即返信）
  - Stage2: フォロワー全体 → テキストでの文脈補足が効く
  - Stage3: フォロワー外 → トピックタグの関連性で配信
  - Stage4: 外部媒体 → Stage3 が安定して初めて到達
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育目的
  - 切り口: 「Threads は『一気に全員に届く』仕組みじゃない。フォロワーの一部→全体→フォロワー外→外部、と4段階で評価が進む。だから初速の1時間で全部決まる」

## 結論（断定で）
- 2026年の AI コーディング界は **Cursor / Windsurf(Devin Desktop) / Cline / Claude Code** の4強。それぞれ哲学が違うので「どれが最強」より「どう使い分けるか」が論点
- Cursor は IDE 内エージェントの最先端（Background Agents / Composer 2.0 / Bugbot 90秒）。日常コーディング 80% の主力としての地位を維持
- Windsurf は Devin Desktop に改名し Cognition の自律エージェント路線に統合。Cascade + Devin の「ローカル+クラウド」ハイブリッドが特徴
- Cline は無料 + 30+ プロバイダ + 5M インストールで「サブスク不要で agent quality」を成立させた。Claude Code 課金者も併用する価値がある
- Claude Code は SWE-bench 87.6%(Opus 4.7) でベンチマーク首位、$100/月で API 換算 $15,000 分の歪み。コスト面で構造的に圧倒している
- gaku_ai_life の立場としては「Claude Code 派ですが、競合の動きも追ってます」のスタンスで投稿すると説得力が出る。1強信者より使い分け派の方が共感を集める
