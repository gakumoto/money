# Threads マネタイズ事例 収集メモ (2026-06-15)

## 全体観

- Threadsは2026年6月時点でも **直接マネタイズ機能 (広告収益シェア・チップ・サブスク) はゼロ**
- 米国限定のクリエイターボーナスは **2025年4月に廃止**、現在は新規申込不可
- Mark Zuckerberg は「10億MAU到達まで広告を本格化しない」と発言、現在は約2億MAU
- 2026年1月から **広告は全世界展開開始** → 還元プログラムの前段階に入った
- 国内の主戦場は **Threads → note 誘導** または **Threads → 自社商品/Brain/メルマガ** の間接型

### 1. note×Threads「3週間ガチ検証」失敗レポート (おじ氏)
- ソース: https://note.com/life_make_better/n/nd157d9ab977e
- 公開日: 2025年 (時期不明、直近)
- 要点（3行以内）:
  - 3週間運用で Threads+3名 / note+2名 / 売上ゼロ。流入も「特に変化なし」
  - AI自動生成投稿は「人の心を動かす内容だったか微妙」と本人が総括
  - 「毎日複数回投稿しても note 流入を期待するのはかなり厳しい」が結論
- 投稿アイデア:
  - 型: 夕方失敗型 / 信頼構築
  - 切り口: 「3週間 Threads 回して note 流入ゼロ。AI 量産投稿が刺さらない理由は1個」
  - gaku の note 0円実績と組み合わせて「俺だけじゃない」共感ネタに変換可能

### 2. 「収益化は投稿より導線」(きりんさん)
- ソース: https://note.com/fine_pony9663/n/n42be7e589f62
- 公開日: 2025-2026年 (記事内に明示なし)
- 要点（3行以内）:
  - 投稿が伸びても売上ゼロは「見込み客のホームへの導入不足」が原因
  - 勝ち筋は「投稿で集客 → 無料noteで教育 → 有料noteで販売」の3層
  - 「詳しくはnoteへ」より「一部だけだが…」で心理的距離を縮める方が機能
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「Threads で月数万稼ぐ人と稼げない人の違い、投稿の質じゃなくて『導線の層数』」
  - gaku 自身の「投稿はある・無料noteまだ・有料note 0円」状態を晒して具体化

### 3. Threads × note 月5万円ロードマップ (akipen blog)
- ソース: https://akipen.com/threads-note
- 公開日: 2025年版
- 要点（3行以内）:
  - 初期目標は Threads 1,000フォロワー、1日1〜5投稿、note 週1記事
  - 980円 × 月100購入 = 月98,000円 が「月5万円ロードマップ」の数字根拠
  - 並行してサブスク型マガジンで安定収益化の上乗せを推奨
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「note 月5万のロジック分解。980円 × 100購入 / 月。100購入って何フォロワー必要か計算した」
  - 「100購入の現実」をネタに、CV 1% 想定なら必要月間流入1万PVという逆算で深掘り

## 注目トピック（即投稿化推奨）

**「3週間検証で流入ゼロ」失敗レポート (#1)** が gaku の note 0円実績と完全に重なる。
「俺もこれ、っていうかこれが普通」型で1本回せる。「実験記」シリーズの最初の信頼補強ネタとして最適。
