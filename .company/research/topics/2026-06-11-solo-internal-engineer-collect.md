# 社内エンジニア 1人体制（ひとり情シス / solo internal engineer）ノウハウ

「ひとり情シス」「ひとり社内SE」の現実 (給与・課題・退職リスク) と、
2026 年に AI / 自動化で 1 人を 3 人分に拡張する具体策をセットで収集。

---

## A. 現実パート — 数字と痛み

### ひとり情シスの年収・課題（2026 年版）
- ソース: https://www.josis365.com/guide/hitori-joushisu/
- 公開日: 2026 年版
- 要点（3 行）:
  - 年収相場 **450〜650 万円**。業務範囲の広さに対して待遇が見合わないと明記
  - 担当範囲は ヘルプデスク / アカウント管理 / セキュリティ / PC 調達まで全部 1 人
  - 退職すると引き継ぎ最低 **3 ヶ月**、運用復旧に **半年以上** かかる事例あり
- 投稿アイデア:
  - 型: 夕失敗型 / 信頼構築
  - 切り口: 「ひとり情シスの年収相場、平均 450〜650 万らしい。広さに対して安すぎる」

### 「ひとり情シスはつらい」の根本理由
- ソース: https://johsyskun.com/journal/158/
- 要点:
  - ITインフラ複雑化 × サイバー攻撃高度化で 2026 年は負担過去最大
  - 「丸投げ」ではなく **共創型アウトソーシング**（Slack / Teams で状況リアルタイム共有）が主流に
  - パスワード共有・構成図作成・セキュリティ最低ラインの 3 点だけは死守
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育
  - 切り口: 「ひとりで全部やる人は、これだけ抑えとけば事故らない 3 つ」

### 中小企業の社内 SE 外注費用相場
- ソース: https://www.power-support.jp/informationsystem/se_itaku/ / https://www.josis365.com/blog/shanai-se-outsourcing-guide/
- 要点:
  - ヘルプデスク中心: 月 **5〜10 万円**
  - IT 定常業務サポート: 月 **5〜10 万円**
  - 開発・運用込み: 月 **10〜50 万円**
  - 「IT 企画（戦略）は社内に残す、ノンコア業務だけ外に出す」が定石
- 投稿アイデア:
  - 型: 朝学び型 / 教育
  - 切り口: 「ひとり情シスの外注費、ヘルプデスクだけなら月 5〜10 万からいける」

## B. 突破パート — AI / 自動化で 1 人を拡張する

### Claude Code で「ひとり社内エンジニア」業務を自動化（10 事例）
- ソース: https://note.com/keito_12kk2/n/n45012d9260f5
- 公開日: 2026 年
- 要点（抜粋）:
  - **Gmail 重要メール抽出**: 1 日 200 件のメールから優先度分類 → Excel 出力（返信下書き付き）
  - **PowerPoint 35 枚を 1 コマンド**: テーマ・対象者・所要時間を渡すだけで AI 画像込みで完成
  - **議事録 → ブログ → サムネ → 自動投稿**: Notta + PREP 法 + Playwright で投稿まで一気通貫
  - **動画編集 10 分**: Whisper 文字起こし → 字幕 → 無音カット → Remotion で組み立て
  - **スマホからリモート PC 操作**: QR コードでセッション引き継ぎ
- 投稿アイデア:
  - 型: 昼進捗型 / 信頼構築
  - 切り口: 「Gmail 200 件、Claude Code で優先度付き Excel に変換した。5 分」

### Copilot × Claude Code 投資対効果
- ソース: https://genai-ai.co.jp/ai-kanri/blog/cc-copilot-use-cases/
- 要点:
  - **月 3 万円の AI で人件費 25〜30 万円分の工数をカバー**
  - 時給換算 **約 190 円** で AI が業務処理
  - 使い分け: 「Office 内の効率化 → Copilot」「業務フロー全体の自動化 → Claude Code」
  - 経費精算: MoneyForward CSV を Claude Code で解析 → 30 分が 5〜10 分に
- 投稿アイデア:
  - 型: 夜振り返り型 / 販売
  - 切り口: 「月 3 万の AI を雇うと、25 万円分の社員ぶん働く。時給 190 円」

### Solo Developer の 7 ワークフロー（英記事だが原則が明快）
- ソース: https://codecondo.com/solo-developer-systems-smart-workflows/
- 要点:
  - 境界線を最初に切る（スコープ膨張の予防）
  - 自動化を「気力の節約装置」と捉える
  - セキュリティはあとから載せず最初に組み込む
  - ログ・エラー監視・依存更新を Day 1 から
- 投稿アイデア:
  - 型: 深夜思考型 / 教育
  - 切り口: 「ひとりで開発する人は『気力を節約する自動化』が全部。気合じゃない」

### ひとりが 10 人より速く出荷できる理由
- ソース: https://codecondo.com/solo-builders-shipping-faster-2026/
- 要点:
  - AI コーディング併用で **タスク完了が最大 55% 速い**（計測結果）
  - 非同期前提・ダッシュボード・通知自動化が「割り込みゼロ」を作る
- 投稿アイデア:
  - 型: 朝学び型 / 信頼構築
  - 切り口: 「AI 使うと開発タスク 55% 速くなる。1 人で 10 人に勝てる理由はこれ」

## C. 統合: 1 人体制で生き残る「3 段ロケット」

1. **守り**: EDR / MFA / バックアップ / パッチ管理 / アカウントライフサイクル の 5 つだけは絶対やる
2. **任せる**: ヘルプデスクは月 5〜10 万円で外注、ノンコアを 1 人から外す
3. **増やす**: Claude Code に Gmail / PPT / 議事録 / 経費精算 / ファイル整理 を任せる。月 3 万円で 25 万円分働く

→ 投稿テーマとして: **「1 人で全部やる人の生存戦略」シリーズ** (5 投稿展開可能)
