# Threads vs X 移行 リサーチ収集 (2026-06-03)

## サマリ

2026年1月、Threads が DAU で X を上回ったことが大きな潮目。海外パワーユーザーの 39% が既に Threads/Bluesky を並行運用、14% は X を完全離脱。一方で国内は Threads 1,230 万 / X 6,800 万 と依然 X が圧倒。「世界では Threads 優勢、日本ではまだ X 主戦場」というギャップが投稿ネタとして強い。
