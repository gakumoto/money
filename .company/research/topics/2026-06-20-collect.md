# Threads アルゴリズム 2026 (2026-06-20 追加収集)

オーナー指定テーマ。gaku_ai_life 運用の「投稿の終わり方・初期1時間の動き・ハッシュタグ・リンク」の設計判断に直結する。

### 返信エンゲージメントが最強シグナル — いいねは過小評価へ
- ソース: https://recurpost.com/blog/threads-algorithm/ , https://postory.io/blog/what-works-on-threads-2026
- 公開日: 2026-04-15（postory）/ recurpost は 2026 通年更新
- 要点（3行以内）:
  - Mosseri「投稿の合計と返信の合計はほぼ同価値」と公式発言
  - 「ナイス！」「絵文字だけ」のエンゲージメントベイトは down-rank の対象
  - いいね・フォロー周りに時間を使うのは無駄。返信獲得が最優先
- 投稿アイデア:
  - 型: 夕方の失敗系 / 教育目的
  - 切り口: 「Threadsで『いいね回り』してた頃、フォロワー全然増えなかった理由がわかった。返信が来ない投稿は、Metaから『広げる価値なし』判定らしい」

### ゴールデンアワー — 投稿後60〜90分が分配を決める
- ソース: https://postory.io/blog/what-works-on-threads-2026 , https://mangaiti.com/threads-growth-2026/
- 公開日: 2026-04-15 / 2026-02-11
- 要点（3行以内）:
  - 投稿後 60〜90分の親密フォロワーの返信速度で、その後の拡散範囲が決まる
  - 30分で20返信ついた投稿 > 24時間で50返信ついた投稿（拡散優先度）
  - 投稿したらアプリを閉じない。返信に張り付くだけで伸びが変わる
- 投稿アイデア:
  - 型: 昼進捗 / 教育目的
  - 切り口: 「投稿してから1時間、スマホ触ってるか触ってないかで伸びが2倍違う。アルゴリズムが見てるのは『最初の30分で会話が立ち上がったか』だけ」

### 4ステージ評価 — フォロワー → 全フォロワー → 非フォロワー → 外部
- ソース: https://addness.co.jp/media/threads-algorithms/
- 公開日: 2026-01-16（2026-06-18 更新）
- 要点（3行以内）:
  - Stage1=一部フォロワー → Stage2=全フォロワー → Stage3=非フォロワー（おすすめ）→ Stage4=外部プラットフォーム
  - 各ステージで「保存」「返信」「滞在時間」が判定材料。次のステージに進むかが決まる
  - 1段目で会話が立ち上がらないと2段目に行かず、フォロワーにすら届かないまま終わる
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「Threadsって投稿が4段階で審査されてる。1段目のフォロワー反応で落第すると、残りのフォロワーにすら届かないまま終わる。だから『最後の一行で問いかける』が効く」

### 問いかけ語尾でリプ3倍 — 「あなたはどう思いますか？」
- ソース: https://mangaiti.com/threads-growth-2026/
- 公開日: 2026-02-11
- 要点（3行以内）:
  - 投稿の末尾に open question を入れるだけでリプライ数が3倍以上に増えた事例
  - 「いいねしてください」より「保存してね」「コメントで教えて」が圧倒的に有利
  - 3-2-5の法則: 毎日3投稿 / 各投稿2往復返信 / 他者へ5件エンゲージ
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「投稿の最後を『〜だと思う』で終わらせるのと『あなたはどう思う？』で終わらせるの、リプ数が3倍違うらしい。これ知ってから、語尾だけは絶対に問いかけで締めるようにしてる」

### ハッシュタグは1個まで — 連発はスパム判定
- ソース: https://www.threads.com/@kudooo_ai/post/DVRqJkNkmlI/ , https://mangaiti.com/threads-growth-2026/
- 公開日: 2026年通年（kudooo_aiの投稿は2026春）
- 要点（3行以内）:
  - Threadsはトピック機能で1投稿1タグのみ設定可能
  - X感覚で複数ハッシュタグを並べるとスパム警戒対象になる
  - 共起語（同じ意味の単語）を本文中に自然に入れる方がアルゴリズムに効く
- 投稿アイデア:
  - 型: 夕方の失敗系 / 教育目的
  - 切り口: 「Xの感覚でThreadsにハッシュタグ並べてた俺、全部スパム扱いされてたっぽい。Threadsは1投稿1タグだけ、あとは本文の単語でAIが判定してる」

### Threads が URL 投稿を再評価 — Mosseri が公式に発言
- ソース: https://recurpost.com/blog/threads-algorithm/
- 公開日: 2026 春〜（Mosseri が「1か月以上テスト中」と公式コメント）
- 要点（3行以内）:
  - 「Threadsはリンク嫌い」は古い説。2026 はリンクを含む投稿の評価を上方修正中
  - ただし「リンクを貼るだけ・本文薄い投稿」は依然として弱い
  - Threads内で完結する読み応え + 補足としてのリンク、の構造が伸びる
- 投稿アイデア:
  - 型: 夜の振り返り / note 導線
  - 切り口: 「『Threadsはリンク貼ると伸びない』は2025までの話だった。Mosseriが公式に『リンク投稿の評価上げてる』って言ってる。本文ちゃんと書いてから貼るならOKってこと」

### 「Dear Algo」— ユーザーがアルゴリズムを直接調教できる新機能
- ソース: https://recurpost.com/blog/threads-algorithm/
- 公開日: 2026年（実験提供中）
- 要点（3行以内）:
  - For You の表示内容を「これ見たい / これ見たくない」とユーザーが直接指示できる機能をテスト
  - 投稿側からすると「ターゲット読者の Dear Algo に乗りたい」という新しい設計観点が生まれる
  - 「あなたの○○観をぶち壊す投稿」のような、能動的に登録されるテーマ性が効く
- 投稿アイデア:
  - 型: 深夜思考 / 教育目的
  - 切り口: 「Threadsに『これ見たい / 見たくない』をユーザーが直接登録できる新機能が来てる。ぼくらの投稿は『誰かのお気に入りに登録される』時代に入った」
