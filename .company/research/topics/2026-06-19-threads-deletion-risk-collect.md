# Threads アカウント削除リスク・対策 最新リサーチ (2026-06-19)

## 全体サマリ (3行)
- **2026年1月のThreads広告配信全世界開始**で Meta は「BOT・低品質コンテンツ」排除を強化。AI運用アカウントが「冬のバンまつり」と呼ばれる規模で凍結されている。
- **凍結→異議申し立て→削除**の動線が確定。永久削除は凍結後30〜180日窓で確定する。新規アカウント作成は「ban evasion」で即再BAN。
- **危険行動の核は3つ**: ①バズ直後のプロフィール編集 ②大量返信時のいいね代用 ③15分で100件超のアクション。AIテキストの「低パープレキシティ」(均質リズム) も自動検知対象。

## 集めた一次情報

### 1. 2026年「冬のバンまつり」— AI運用アカウントが大規模凍結
- ソース: https://web-butler.jp/threads-ban/
- 公開日: 2026年（継続更新）
- 要点:
  - 2026年1月にMeta社がThreads広告配信を全世界開始。BOTと低品質コンテンツの排除が優先される
  - 「低パープレキシティ検知」— 完璧文法・均質リズムの機械的文章が自動排除対象
  - 危険ジャンル3つ: メンタルヘルス系（感情と文体の不一致）/ 昭和レトロ系（AIの事実誤認）/ AIプロンプト紹介系（コピペ多発）
  - ビデオセルフィー提出は逆効果。実在性は証明しても「無実」は証明しない
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「Threadsで凍結されてるアカウントの共通点を見てたら、AI文章の『リズムが均質すぎる』が一番効いてた。完璧に書こうとするほど消される」

### 2. 凍結→削除タイムライン — 30〜180日窓で永久削除確定
- ソース: https://postory.io/blog/threads-account-banned
- 公開日: 2026年（継続更新）
- 要点:
  - 2025年5月末と2026年3月末に大規模BANウェーブ。Facebook/Instagram/Threads同時に数万件影響
  - 異議申し立て応答: 7〜14日以上
  - 永久削除確定窓: 凍結後30〜180日
  - 誤検知(false positive)の自動巻き戻し: 1〜2週間で起きる場合あり
  - 新規アカウント作成は ban evasion で即再BAN
- 投稿アイデア:
  - 型: 夜振り返り型 / 信頼構築
  - 切り口: 「Threads凍結されたら『新しいアカウント作り直そう』が一番ダメ。ban evasion判定で即再凍結。1.5万フォロワーごと吹き飛ぶ前に守る順序がある」

### 3. アカウント停止の原因7選（行政書士監修）

  - 異議申し立て5原則: 事実のみ冷静に / 運用目的明示 / 証拠添付 / 再遵守約束 / ガイドライン引用
  - 2回以上却下 or 心当たりなしの永久停止は専門家相談ライン
- 投稿アイデア:
  - 型: 教育目的 / リスト型
  - 切り口: 「Threadsアカウントが止められる原因、行政書士の整理だと7個に絞れる。一番見落とされてるのが⑦Instagram連鎖停止。Threads側で何もしてないのに Instagram の違反で巻き込まれる」

### 4. シャドウバン復帰の正解 — 48〜72時間の完全沈黙
- ソース: https://mangaiti.com/threads-shadowban-check/
- 公開日: 2026年（継続更新）
- 要点:
  - 確認方法: ①ユニークハッシュタグを別アカウントから検索 ②シークレットブラウジングで自プロフ表示 ③非フォロワー由来リーチの急減 ④他人にユーザー名を検索してもらう
  - 復帰: 48〜72時間「投稿/いいね/コメント/フォロー全部やめる」が正解。AIに「不審な動きが止まった」と認識させる
  - 軽症2〜3日 / 重症は数週間
  - 復帰直後はバルクではなく質の高い対話から再開
- 投稿アイデア:
  - 型: 夕失敗型 / 教育目的
  - 切り口: 「Threadsで急にインプ落ちた時、焦って投稿しまくるのが一番回復遅らせる。正解は『48〜72時間ぜんぶ止める』。AIに不審な動きが終わったと認識させる」

### 5. バズ時の安全モード — いいね連打とプロフ編集が地雷
- ソース: https://note.com/murikamome/n/n9d59fded13ea
- 公開日: 2026年
- 要点:
  - 凍結直前の共通行動: 「大量返信対応でいいね代用」「バズ直後のプロフィール編集」
  - 好意的意図でも「短時間の機械的大量アクション」に見える
  - 環境不安定（VPN切替/IP変動/複数端末切替）も疑い対象
  - 不完成プロフィール+作成直後の急激アクティブ化は危険
  - 再発防止: プロフ完成 / 表示名ID固定 / 2段階認証 / 初週は大量アクション禁止 / 非公式ツール最小化 / ローカル資産保管 / 本拠地(note等)と避難先明記
- 投稿アイデア:
  - 型: 夕失敗型 / 体験談
  - 切り口: 「バズった直後に『よし、プロフィール整えとこ』が凍結トリガーだった。大量リプ来てる時に編集すると『不審な短時間操作』判定。バズ中は触らない」

### 6. シャドウバン解除の実運用ルール（リンクは必ずコメント欄）
- ソース: https://mangaiti.com/threads-growth-2026/
- 公開日: 2026年版
- 要点:
  - シャドウバン確定基準: 直近1週間の投稿インプ全部が通常の3割以下
  - 解除手順: 外部リンク連投/大量フォロー/コピペ投稿を即停止 → 48〜72時間は1日1〜2本のテキストのみ → 24〜48時間の完全放置
  - 復帰後は外部リンクを必ずコメント欄に配置
  - 解除最短48時間、長いと2週間
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「Threadsで外部リンクを本文に貼るのが2026年で一番効率悪い。プロフ遷移とコメント欄経由のほうが配信も収益化も伸びる」

## 結論

Threadsアカウント削除リスクは2026年に入って構造的に増加した。**広告配信開始と連動してMeta側のAI検知が高解像度化**しており、AI運用アカウントは「均質リズム」「短時間大量アクション」「リンク連投」の3軸で自動排除されやすい。

オーナーの運用文脈で重要なのは:
1. **gaku_ai_lifeの「実験記」キャラはむしろ追い風**。失敗・0円・温度感を出すスタイルは「低パープレキシティ」判定を回避する
2. **バズ時のプロフィール編集禁止**を運用ルールに追加すべき（過去ヒット投稿の直後に編集する習慣がある場合は地雷）
3. **note を本拠地として明記する固定投稿**は削除リスクヘッジとして即実装価値あり
4. **危険ワード/9:1ルール**は既存メモ(threads-deletion-risk.md)と整合。今回の追加分は「行動パターン」(編集タイミング/アクション速度)側
