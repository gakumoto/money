### 駆け出しエンジニア1年目 副業4種比較（4ヶ月0円→ブログだけ月10万）
- ソース: https://youmanavisions.com/career-change/post-117824/
- 公開日: 不明（記事内で1年実績データ公開）
- 要点（3行以内）:
  - 1年目に試した4副業の生データ: YouTube動画編集（月30h×13ヶ月＝0円）/ ゲーム開発（月60h×4ヶ月＝0円）/ プログラミング副業（月30h×2ヶ月＝月3〜5万）/ 個人技術ブログ（月40h・初期月5,000円→2年目で月10万）。
  - 副業1年目は「4ヶ月連続0円」が普通。5ヶ月目でやっとブログが¥5,000着金、そこから2年で月10万到達。
  - 利用したサイトは「エンジニアデータバンク」と「ITプロパートナーズ」の2つだけ。
- 投稿アイデア:
  - 型: 夕失敗型 → 夜振り返り
  - 切り口: 「駆け出し1年目で副業4つ試したら3つは0円だった話。動画編集13ヶ月とゲーム開発4ヶ月で稼げたのは合計0円。唯一伸びたのはブログ」
  - 補足: gaku の note 0円・60日月10万ロードマップと同じ温度感で語れる一次資料。「最初4ヶ月0円が普通」のラインが救いになる。

### AI副業で月10万を超えるためにやった5つのこと（時短=商品化）
- ソース: https://aifreelancelab.com/ai-side-job-100k-yen-engineer/
- 公開日: 2026年（明記なし、記事タイトルに「2026年の実践録」）
- 要点（3行以内）:
  - 「AIを"使ったサービス"ではなく"効率化した労働力"として売る」が核。作業を1/3に圧縮した分を自分の利益に変換する設計。
  - 最初の案件は「知人企業のブログ更新が追いつかない」課題に声をかけて月3万からスタート。営業ゼロ。
  - 自動化＋テンプレ化で週5〜6時間で月10万を維持。1〜2週間で作る小さなニッチツールを月額¥500〜¥1,000で数十人に売る、を併用。freee で副業1円目から記帳。
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「AI副業で月10万行く人と行かない人の差は『AIを商品にしてるか、効率化のレバーとして使ってるか』らしい。前者は値崩れ、後者は時給が上がる」
  - 補足: gaku の Claude Code 文脈と直結。「最初の案件は知人」の話は note 0円層に効くフック。

### 2026年エンジニア副業の時給相場 平均¥3,350／土日6時間モデル
- ソース: https://app-tatsujin.com/engineer-side-job-guide-2026-weekend/
- 公開日: 2026年（2025-Q2データ参照）
- 要点（3行以内）:
  - 副業エンジニア平均時給は ¥3,350／h。プラットフォーム別だと Qiita Job Change ¥3,200〜3,800、Zenn ¥2,800〜3,300、App-tatsujin ¥3,800〜4,500。

- 投稿アイデア:
  - 型: 朝学び型 / 信頼構築
  - 切り口: 「2026年のエンジニア副業、時給平均¥3,350らしい。週6時間で月8万。"GitHubにデモ置いてるかどうか"で選考通過率が変わるという数字」

### 駆け出しが副業でやりがちな失敗4つ（RUNTEQ）
- ソース: https://runteq.jp/blog/working/side-job/21114/
- 公開日: 不明（RUNTEQ運営記事）
- 要点（3行以内）:
  - 失敗パターン: ①報酬に見合わない低単価受注 ②実現不可能な難度の案件を受ける ③リモートにこだわらず移動負担を抱える ④本業に支障する大規模案件。
  - 「1〜2年の実務経験を積んでから副業に取り組むのが効率的」と提言。即副業より地力。
  - 案件獲得6ルート: クラウドソーシング／スクール講師／副業エージェント／SNS／企業直営業／人脈。スクール卒は独学より信頼度が高い、と明示。
- 投稿アイデア:
  - 型: 夕失敗型 / 教育目的
  - 切り口: 「駆け出しSEが副業で爆死する4パターン。①安すぎる案件 ②難しすぎる案件 ③移動ありの案件 ④デカすぎる案件。"取れるから取る"が一番危ない」
  - 補足: gaku の「副業0円期」と並走させやすい。「即副業より1〜2年実務」の主張は反論余地ありで議論型にできる。

### AI活用副業者は月収1.8倍（¥46,000 vs ¥25,000）
- ソース: https://www.sbbit.jp/article/cont1/178762
- 公開日: 2026年（「2026年版 最強AI副業ランキング」記事内）
- 要点（3行以内）:
  - AIを活用している副業者の平均月収は約 ¥46,000、未活用は約 ¥25,000。差は 1.8 倍。
  - 政府の副業解禁＋AIツール普及＋スキルのオンライン化で「副業参入のハードルがこれまでにないほど下がった」と総括。
  - 超初心者でも「まず5万円」は現実的な水準として紹介。月100万のような上澄みではなく中央値の話。
- 投稿アイデア:
  - 型: 朝学び型 / 信頼構築
  - 切り口: 「AI使ってる副業者の平均月収¥46,000、使ってない人は¥25,000。"AI使うか使わないか"で月収が1.8倍違うっていうデータ、駆け出し層こそ効くと思う」
  - 補足: 数字1個でフックが立つ。「AI使うだけで時給上がる」のシンプルな構造を朝学びで配れる。
