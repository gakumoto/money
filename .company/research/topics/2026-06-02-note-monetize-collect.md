## 価格設定の指標

### 平均価格・相場
- 実用ノウハウ系: **平均 1,842円**
- 読み物系: **平均 983円**（約1.9倍差）
- ライフログ・体験談: 300〜500円
- 専門ノウハウ・テンプレ: 800〜1,500円
- 本格講座・PDF教材: 2,000円〜

### メンバーシップの黄金パターン
- ソース: https://note.com/notemag/n/n65bfc3cf1d88
- **月額500円が入門価格**（売上が高いMSの多くが採用）
- **2〜4プラン構成、価格差は3倍**（例: 500円 → 1,500円 → 5,000円）
- 「最も選んでほしいプランを真ん中の価格に置く」=松竹梅の心理学
- 価格範囲: 無料会員100円〜50,000円、プレミアム会員100円〜100,000円

### 有料記事の段階的値上げ法
- 300円でテスト販売 → 10人売れたら 500円 → 反応良ければ 1,000円
- 定期購読マガジンは途中で価格変更不可（要注意）

## Threads→note 動線設計

### 4段階分離モデル
- ソース: https://note.com/jikoseityou_9182/n/n75e49cbed4eb / https://note.com/cute_kalmia194/n/n07700e672490
- 公開日: 2026-04〜05
- 要点:
  1. **投稿** = 興味を止める（全部説明しない）
  2. **プロフィール** = 何の人かを見せる
  3. **固定記事** = 読む順番の地図
  4. **note記事** = 詳しく整理する深堀り
- よくある失敗:
  - 投稿1個で全部背負わせる
  - note記事への動線を作る前に販売圧をかける
  - 役割の混在で読者が迷う

### Threads→noteの3つの誘導型
- ストーリー型: 失敗・体験を投稿→結末はnoteで
- ハウツー型: 手順の一部を投稿→残りはnoteで
- データ・実績型: 結果や数字を先に出す→理由をnoteで
- **note読者の約70%はSNS経由** = SNS発信なしで売上は伸びない

## 無料/有料の境界線
- 記事全体の **約30%を無料公開** が目安
- 無料: 導入・概要・基本概念
- 有料: 具体的なノウハウ、手順、戦略、体験談（=「自分にしか書けない部分」）
- 「この先が絶対に読みたい」と思わせる位置に有料ラインを引く

# 投稿アイデア（9件）

### 1. 「育児カテゴリのトップ10中7人が1年以内の新規」
- 型: 朝学び / 教育目的
- 切り口: 「note 育児カテのメンバーシップ売上トップ10、7人が新規参入だった。先発が有利と思ってたのは勘違い。」
- 数字を投稿の枕に置く・命令型ラスト「今からでも遅くない、書け。」

### 2. 「実用1,842円 vs 読み物983円」
- 型: 教育目的
- 切り口: 「note の有料記事、実用系の平均は1,842円。読み物系は983円。約2倍違う。/ 自分の note、どっち側か分かってる？」
- バズ要素: 千円単位・問いかけで終わる

### 3. 「月600円×1,700人=102万円」(IKさん)
- 型: 夜振り返り / 信頼構築
- 切り口: 「月600円。1,700人集めれば102万円になる。/ バズ狙いの単発じゃなく、安定の方が強い、を地で行ってる人がいた。」
- 弱さ枕詞: 「ずっとバズ狙いだった自分が恥ずかしい。」

### 4. 「メンバーシップは500円スタート/3プラン/価格差3倍」
- 型: 朝学び / 教育目的
- 切り口: 「note メンバーシップで売れてる人の構成、ほぼ全員同じだった。/ 500円→1,500円→5,000円。価格差3倍。真ん中を売る。」
- 「松竹梅の心理学そのまま」

### 5. 「Threads→note の4段階分離」
- 型: 教育目的 / ハウツー
- 切り口: 「Threads から note に流れない人、たぶんこれ。/ 投稿で全部説明してる。プロフで全部詰めてる。固定記事に全部入れてる。/ 役割分けろ。」
- 命令型ラスト

### 6. 「読者の70%はSNS経由」
- 型: 教育目的
- 切り口: 「note 単独で勝負してる人へ。/ 売れてる人の読者、70%は SNS から来てる。/ note 書くより、Threads 直せ。」
- 短文・断定で締める

### 7. 「あべようこ 月3,800円×開設初日100人 = 38万円」
- 型: 信頼構築 / 事例紹介
- 切り口: 「月3,800円のメンバーシップを開設した初日、100人集まった人がいる。/ 価格じゃない、信頼の積み上げ。」

### 8. 「価格変更できない罠：定期購読マガジン」
- 型: 教育目的 / 注意喚起
- 切り口: 「note の定期購読マガジンは、開始したら価格変更できない。/ 知らずに 300円で出して、後悔してる人を何人か見た。/ 最初の値付け、命。」
- 弱さ枕詞 + 警告

### 9. 「300→500→1,000円 段階値上げ法」
- 型: 朝学び / ハウツー
- 切り口: 「初めての有料note、いきなり 1,000円つけるな。/ 300円で出して、10人売れたら 500円。反応良ければ 1,000円。/ 階段で上がる。」
