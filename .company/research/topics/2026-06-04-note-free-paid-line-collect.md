# 2026-06-04 リサーチ：note「無料/有料の線引き」と売れる構成

## 全体観

note 公式が **約30万件の有料記事を分析**したデータ（2024年12月〜2025年11月）が出揃い、「売れる記事の型」が定量化された。論点は3つ：
1. **価格帯**：実用系=1,800円 / 読み物系=980円が売上上位20%の中央値
2. **無料/有料比率**：基本「無料7 : 有料3」だが、実用ノウハウは無料エリアを読み物系の **1.5倍** とる
3. **文字数と売上に相関なし**（実用系 -0.023 / 読み物系 0.011）。長く書く＝売れる、は嘘

「弱さ枕詞→未完語尾→千円単位」のテンプレと相性が良い。投稿の型としては **朝学び型 / 教育目的** で即使える。

### 1. note 30万件分析：売れる記事の最適価格は実用1,800円・読み物980円
- ソース: https://prtimes.jp/main/html/rd/p/000000360.000017890.html
- 公開日: 2026-01-07（note株式会社プレスリリース）
- 要点（3行以内）:
  - 売上上位20%の中央価格は実用1,842円 / 読み物983円（**1.9倍差**）
  - 実用ノウハウは無料エリアの文字数が読み物の **約1.5倍**（先に「元が取れる」と提示）
  - 文字数と売上の相関はほぼゼロ（実用 -0.023 / 読み物 0.011）
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「note の有料記事、長く書けば売れると思ってた。30万件分析の答えは『相関ゼロ』だった」

### 2. 無料部分の黄金比は「7:3」、無料はあくまで試食コーナー
- ソース: https://note.com/ai_hitsujisan/n/n364f6324556e
- 公開日: 2026年（最新版・日付は記事内に明記なし、参照は2026-06-04）
- 要点（3行以内）:
  - 無料7：有料3 を基本比率に。短い有料部分でも、無料側で問題提起と信頼構築ができていれば売れる
  - 無料部分の役割は3つ：①悩み共感 ②ベネフィット明示 ③個性を伝える
  - 有料は「数値事例 / ステップ手順 / 実績」で具体化
- 投稿アイデア:
  - 型: 夕失敗型 / 信頼構築
  - 切り口: 「有料 note が売れない人、無料部分を出し惜しみしすぎ。試食コーナーで満腹にさせるから本編が買われる」

### 3. 無料部分の4段構成テンプレ：フック→立ち位置→気づき→導線

  - 切り口: 「note の無料部分、4段で書くだけで購入率が変わる。フック→立ち位置→気づき→導線」

### 4. 売れない人がやってる「無料部分の出しすぎ / 出さなさすぎ」2パターン
- ソース: https://note.com/firm_rabbit1903/n/n0e815a15b099
- 公開日: 2026年
- 要点（3行以内）:
  - 失敗①：出しすぎ→「無料でこれなら、有料はもっと薄いのでは？」と思われる
  - 失敗②：出さなさすぎ→誰にも買われない
  - 無料は「悩み明確化＋信頼構築＋部分ヒント」、有料は「全体像＋再現性ある具体策」と役割分離
- 投稿アイデア:
  - 型: 夕失敗型
  - 切り口: 「有料 note の線引き、間違いやすい2パターン。出しすぎても出さなさすぎても売れない」

### 5. 段階値上げ戦略：300円テスト → 10人売れたら500円 → 1,000円
- ソース: https://www.sungrove.co.jp/note-paid-article/
- 公開日: 2026年
- 要点（3行以内）:
  - 初の有料記事は **300円でテスト**。10人売れたら500円、反応良ければ1,000円へ段階値上げ
  - 手数料は **クレカ15% / キャリア決済25%**。300円=実質手取り255円
  - 読者の約70% は **SNS経由** で流入。発信なしに売上は伸びない
- 投稿アイデア:
  - 型: 昼進捗型 / 教育目的
  - 切り口: 「初の有料 note は 300円から。10人売れたら 500円。値上げの判断基準が明確になると怖くなくなる」

### 6. 実用系1,800円・読み物系980円の「根拠」と収益最大化3手順
- ソース: https://note.com/shiodome_098/n/ncaaed7795642
- 公開日: 2026年
- 要点（3行以内）:

  - 読み物系が980円どまりの理由：感情的価値は金銭化しにくく、一読で満足＝再閲覧されない
  - 価格設定の前提として「自分の記事が道具か体験か」を分類することが先
- 投稿アイデア:
  - 型: 夜振り返り型 / 教育目的
  - 切り口: 「note の値段、適当につけてた。実用と読み物で 1.9倍差があるのは『再閲覧されるか』の違いだった」
