# Sora AI 動画生成 × 個人開発 リサーチ (2026-06-03)

## 背景サマリ
- Sora 2 は OpenAI の動画生成 AI。2025年10月にリリース、SNS型アプリ「Sora」も同時公開
- **2026年3月24日**、OpenAI が Sora-2 API の終了 (**サンセット日: 2026年9月24日**) を発表
- 個人開発で Sora 2 API を組み込んだサービスは、9月までに移行必須
- 動画生成技術自体は ChatGPT に統合されて存続。スタンドアロン製品 (Sora アプリ / Sora.com / Sora 2 API) のみ終了

---

## 収集情報

### 1. Sora 2 API 終了とサンセット日確定
- ソース: https://help.apiyi.com/en/sora-2-api-shutdown-alternatives-2026-en.html
- 公開日: 2026-03-24 発表
- 要点（3行以内）:
  - OpenAI が 2026-03-24 に Sora 2 API の終了を公式発表
  - サンセット日 (API 停止日) は **2026-09-24**
  - Sora 2 モデル自体は ChatGPT Plus/Pro 内で存続するが、API 経由のアクセスは消える
- 投稿アイデア:
  - 型: 夕失敗型 / 朝学び型
  - 切り口: 「Sora 2 API、9月で終わるって知ってた？個人開発で組み込んでた人は移行必須」

### 2. Sora 2 API の正確な料金 (秒単位課金)
- ソース: https://costgoat.com/pricing/sora / https://www.eesel.ai/blog/sora-2-in-the-api-pricing
- 公開日: 2026年版
- 要点（3行以内）:
  - **Sora 2 Standard**: $0.10/秒 (720p) — Batch なら $0.05/秒
  - **Sora 2 Pro**: $0.30/秒 (720p) / $0.50/秒 (1024p) / $0.70/秒 (1080p)
  - 12秒のフル尺 Pro (1024p) を1本 → **$6.00**
- 投稿アイデア:
  - 型: 朝学び型 / 数字訴求
  - 切り口: 「Sora 2 Pro で12秒動画作ると $6 (約900円)。1日10本で月27万。これを高いと見るか、安いと見るか」

---

### 3. Sora 2 から Google Veo 3.1 への移行が現実解
- ソース: https://blog.laozhang.ai/en/posts/sora-2-api-vs-veo-3-1
- 公開日: 2026年 (API 終了発表後)
- 要点（3行以内）:
  - Veo 3.1 は 11 項目中 7 で Sora 2 に勝利 (4K対応、音質、縦動画、グローバル、料金、API、レート)
  - サブスク基準で **最大 96% 安い**
  - 移行は **2行のコード変更、30分以内** で完了 (REST 形式が近い)
- 投稿アイデア:
  - 型: 昼進捗型 / 教育型
  - 切り口: 「Sora 2 → Veo 3.1 への移行、コード2行・30分で済んだ。むしろ4Kになって安くなった」

---

### 4. 無料プラン廃止 → Plus 必須化 (2026-01-10〜)
- ソース: https://help.apiyi.com/en/openai-sora-2-policy-change-plus-pro-only-en.html
- 公開日: 2026-01-10
- 要点（3行以内）:
  - 2026-01-10 から無料ユーザーは Sora で動画生成不可
  - Plus ($20/月) 以上が必須に
  - **Plus にはウォーターマーク付き** (商用利用に難)。透かしなしは Pro ($200/月) のみ
- 投稿アイデア:
  - 型: 気づき型
  - 切り口: 「Sora の Plus プラン、商用には使えない。透かし入る。広告・YouTube 収益化狙うなら $200/月の Pro 一択」

### 6. API 課金にはアカウント Tier 2 (最低 $10 チャージ) が必要
- ソース: https://www.aifreeapi.com/en/posts/sora-2-api-pricing-quotas

- 要点（3行以内）:

- 投稿アイデア:
