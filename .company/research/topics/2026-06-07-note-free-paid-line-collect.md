## 1. 売れる有料記事の「5つの構成型」

### 有料note記事の「売れる構成」5つの型（テンプレート付き）
- ソース: https://note.com/takuma_signal/n/n60eb47a4c1c4
- 公開日: 2026年初頭 (推定)
- 要点:
  - **①How-to型**: 手順を追って解説する。最も汎用性が高い基本型
  - **②Before/After型**: 変化を見せて説得力を出す。ビジュアル変化が刺さる
  - **③チェックリスト型**: 自己診断で「自分ごと化」させる
  - **④ケーススタディ型**: 具体例で理解を深める。実例で説得力を出す
  - **⑤フレームワーク型**: 思考の枠組みを提供する。応用可能な思考法
- 投稿アイデア:
  - 型: 朝学び / 教育目的
  - 切り口: 「売れる有料 note は型が5つしかない。How-to / Before-After / チェックリスト / ケーススタディ / フレームワーク」
  - 切り口2: 「自分の note、型がない人読んで。5つの中から1つ選ぶだけで売れ始める」

## 2. クロサキナオ「2026年の余白理論」(売れない原因の再定義)

### 2026年だし、有料記事の売れ方を知っておこう
- ソース: https://note.com/kurosakina0/n/n1f7d3de4409a
- 公開日: 2026年初頭
- 要点:
  - 参入者が増えて読者が「また有料か」「よくある話」と先入観を持つ市場になった
  - 売れない理由は **中身ではなく、書きすぎていること**
  - 読者が考える前に「作者が全部言ってしまっている」のが原因
  - 2026年の売れる鍵 = **余白**。読者が立ち止まって考える空間を残す
  - 親切すぎる説明は逆効果
  - 「声なき読者」は静かに見ていて、ある日突然「言葉が刺さった」と現れる
- 投稿アイデア:
  - 型: 夜振り返り / 深夜思考
  - 切り口: 「note が売れないのは『書きすぎ』。2026 年は余白で勝つって話」
  - 切り口2: 「読者を考えさせる余白を作る — 親切すぎる note は売れない時代になった」

## 3. 信頼を有料化する「循環フロー」(無料→導線→有料→無料に還す)

### 買われる有料記事の構成テンプレ — 信頼を収益に変える再現性のある書き方
- ソース: https://note.com/note_mama_10mann/n/n1573c3239757
- 公開日: 2026年 (note で月10万を達成したママの実体験)
- 要点:
  - **3段階フロー**: 無料記事(共感・信頼構築) → 導線記事(次のアクション促進) → 有料記事(再現ノウハウ具体化) → また無料で還す
  - **5段階構成テンプレ**:
    1. 導入: 前記事との連続性を示す
    2. 前提整理: 読者の現状を認める一文
    3. メイン: 「型＋実例」を 3〜5ステップ
    4. 感情の一文: 行動への背中押し
    5. 導線設計: 次テーマへのつながり
  - 公式: **「体験の濃度 × 構成の再現性 = 信頼の有料化」**
  - ママ層に効く軸: 時間とお金の両立可能性の実証 / 「才能より設計」/ 具体的な金銭目標 (習い事代・旅行代)
- 投稿アイデア:
  - 型: 朝学び / 信頼構築
  - 切り口: 「有料 note は『売る』より『整える』— 無料→導線→有料→無料に還す循環で月10万作った人の構成」
  - 切り口2: 「体験の濃度 × 構成の再現性 = 信頼の有料化。この公式を知ってから note が売れ始めた」

## 4. メンバーシップ複数プラン「3倍刻み」公式

### note 公式が3000件のメンバーシップを分析してわかったヒント
- ソース: https://note.com/notemag/n/n65bfc3cf1d88
- 公開日: 2026年 (note 編集部の一次分析)
- 要点:
  - **初期価格は月額500円推奨** (試しやすい入口として機能)
  - **推奨プラン数: 2〜4プラン** (売上が高いメンバーシップの共通点)
  - **価格差は約3倍刻み**: 例 500円 → 1,500円 → 5,000円
  - 説明文の最適長: **200〜250字前後** (プラン加入で何が得られるかを簡潔・具体に)
  - 8つのカテゴリーすべてで「ベーシック500 / スタンダード1500 / プレミアム5000」の3段構成
- 投稿アイデア:
  - 型: 教育目的 / 販売
  - 切り口: 「note メンバーシップは3倍刻み。500/1500/5000 がデータ的に勝ち構造」
  - 切り口2: 「メンバーシップで詰まる人は、プランが1つしかない。3つに分けるだけで売上が変わる」

## 5. ケースE: 「投稿後放置 → 翌週初売上」の3点改修

## 7. Threads × note 連動の「収益化を急ぎすぎる」失敗

- 要点:

## gaku_ai_life への接続メモ

- 昨日の「70:30 黄金比 / 価格段階」と組み合わせると、Phase 2 (note 導線設計) の骨格が完成する:
  - **構成型**: How-to 型 か ケーススタディ型 を主軸に (gaku_ai_life の文脈と合う)
  - **無料部分**: 2,500〜3,500字、結論先出し → 再現手順を有料側へ

- Threads は **撒く期間 (3ヶ月)** と割り切る。収益化を急ぐと逆に売れなくなる
