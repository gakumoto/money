# note 無料/有料の線引きリサーチ (2026-06-08)

「どこまで無料で出すか」「どこから有料にすると売れるか」という構成設計の一次情報を収集。
価格論は既存の `2026-06-08-note-monetize-collect.md` に集約済みで、本ファイルは **無料エリアの設計** に絞った深掘り。

### 無料エリアの最適文字数は3,500〜4,000字
- ソース: https://note.com/natsuo_money/n/nf0a688dd17cc
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - 1,000〜1,500字では「買う理由」も「期待感」も生まれず離脱される。
  - 3,500字あれば離脱されずに購入欲求を満たせるラインに乗る。
  - 長く書く=売れる ではなく「読者の心が動く長さ」が3,500字前後。
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「有料note、無料部分を1,500字で済ませて全然売れなかった話。買う気を作るには3,500字いる。短いとそもそも『買う理由』が生まれてない」

---

### 無料/有料の比率は30〜50%が黄金ライン
- ソース: https://note.com/yuragu338/n/n95ad3d2a836c
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - 無料部分は全体の **30〜50%** が読者離脱と購入欲求のバランス最適。
  - 無料パート = 「なぜこのテーマか・どんな悩みを解決するか」
  - 有料パート = 「具体的にどうやるか」を惜しまず書く。
- 投稿アイデア:
  - 型: 昼進捗型 / 教育目的
  - 切り口: 「note の有料記事、無料を3割で切るか5割で切るかで売上が変わる。3割未満は『内容見えない』で離脱、5割超は『無料で十分』で離脱。間がスイートスポット」

---

### 無料エリアの構成は PASO 型（Problem → Affinity → Solution → Offer）
- ソース: https://note.com/natsuo_money/n/nf0a688dd17cc
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - Problem（問題提起）→ Affinity（共感）→ Solution（解決策のチラ見せ）→ Offer（有料部分の価値を予告）。
  - 「チラ見せ」までは無料、「具体手順」は有料というラインで切る。
  - この4ステップ全部入れて初めて「先を読みたい」が生まれる。
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「売れる有料noteの無料部分、構造は4つだけ。問題提起 → 共感 → 解決策のチラ見せ → 有料部分の予告。チラ見せまでが無料、手順は有料。これ守れば3,500字書く意味が出る」

---

### 売れない有料記事の共通パターン: 無料部分が「ただの説明」
- ソース: https://theboss.jp/why-note-paid-articles-do-not-sell/
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - 売れない記事は無料部分が「説明・前置き」で終わっていて、感情が動かない。
  - 売れる記事は無料部分で **共感 → 変化の物語 → ベネフィット提示** が完結している。
  - 「失敗談・試行錯誤プロセス」が感情の引き金になる（一般論で書くと死ぬ）。
- 投稿アイデア:
  - 型: 夕失敗型 / 共感
  - 切り口: 「初めての有料note、無料部分が『これから○○について書きます』みたいな前置きで埋まってた。読者は説明じゃなくて『この人ヤバい目に遭ったんだな』で買う。前置きは敵」

---

### タイトル+導入文の3要素: 悩みの代弁 / 未来の提示 / 信頼性の証明
- ソース: https://www.sales-dx.jp/blog/note-informative-notes
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - 売れる記事の冒頭は「悩みを代弁 → この記事で得られる未来 → 著者が語っていい根拠」の3点セット。
  - 1つでも欠けると購入率が落ちる。順番もこの並びがハマる。
  - 無料エリアの「最初の300字」で買うかどうかの50%が決まる、と複数記事で一致。
- 投稿アイデア:
  - 型: 朝学び型 / 教育目的
  - 切り口: 「note の有料記事、最初の300字で勝負の半分が終わってる。①悩み代弁 ②得られる未来 ③なんで君が語れるの？ この3つを冒頭で並べる。順番もこの通り」

### 7:3の法則: 全体70%を価値ある無料コンテンツに、有料は30%
- ソース: https://note.com/kei_blogger_/n/ne08ecbceedb0
- 公開日: 2026年（参照記事）
- 要点（3行以内）:
  - **アカウント単位での無料70:有料30** が成功クリエイターの共通パターン。
  - 1記事内の比率ではなく「アカウント全体の無料記事ボリューム vs 有料」。
  - 信頼資産を積んでから初めて30%が売れる。逆順は絶対に売れない。
- 投稿アイデア:
  - 型: 夜振り返り型 / 信頼構築
  - 切り口: 「note で月10万行く人、アカウント全体で『無料70:有料30』を守ってるらしい。先に有料出したい衝動を抑えて、7割は無料で価値出す。ぼくは今この比率を試算してる段階」
