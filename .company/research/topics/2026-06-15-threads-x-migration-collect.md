# 2026-06-15 リサーチ: Threads vs X 移行

## 概要
- 2026年1月時点で Threads のモバイル DAU が X を逆転（1.415億 vs 1.25億）
- 逆転は突発ではなく 2025年10月下旬〜11月上旬から進行
- Threads MAU は 3.5〜4億超、日本は約 1,000万〜1,700万MAU と推定
- 日本では X が依然強い（人口の2/3が利用）が、Threads は 2年で約4倍に拡大
- Web では X が依然圧倒的（1.45億 vs 0.085億）→ モバイル限定の逆転

- ソース: https://www.gizmodo.jp/article/threads-is-now-clearly-more-popular-than-x/
- 公開日: 2026-01-19

  - Grok の性的ディープフェイク問題と各国の取り締まり強化が背景

  - 型: 朝学び型 / 教育目的

### モバイル前年比 Threads +37.8% / X -11.9%
