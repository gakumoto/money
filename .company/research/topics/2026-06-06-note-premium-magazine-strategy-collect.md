# 調査: note プレミアム・マガジン戦略（2026-06-06）

## 目的
gaku_ai_life の 60 日で月10万円ロードマップ（期限 2026-07-13）に向けた、
note 課金導線の判断材料を最新数字で更新する。投稿ネタとして使える具体数字を優先。

## 結論（断定）

1. **メンバーシップが note 内で最速成長中**。売上前年同月比 +81.3% / 購入件数 +86.3% / 売上クリエイター数 +100.5%（2025年11月実績、note公式 2026-01-07 発表）。
2. **実用ノウハウ系は読み物系の 1.9 倍で売れる**。平均 1,842 円 vs 983 円。AI 副業はど真ん中。
3. **定期購読マガジンは手数料 20%、メンバーシップは 10%**。月10万を狙うなら手数料で月1万円違う。
4. **定期購読マガジンには「月1回以上の更新義務」あり**。メンバーシップにはない。週次運用が無理なら定期購読は重荷。
5. **noteプレミアム（月 500 円）は必須**。価格上限 1万→5万円、定期購読申請権、予約投稿、マガジン作成数上限解放。月10万狙うなら入らない理由がない。
6. **「育児カテゴリ」売上TOP10のうち7人が1年以内の新規参入者**（noteプレス）。新規でも勝てるジャンルが存在する＝AI副業も同様の伸び余地あり。
