### LCEL のパイプ記法でチェーンを 1 行で組む
- ソース: https://future-coders.net/langchain入門2-プロンプト-leclの使い方/
- 公開日: 2024 (Future Coders LangChain 入門シリーズ)
- 要点:
  - LCEL = LangChain Expression Language。Unix の `|` のように要素を連結
  - 最小構成は `chain = prompt | llm | output_parser` の 1 行
  - `ChatPromptTemplate.from_messages([("system", "..."), ("user", "...")])` がチャット用の推奨形
  - `chain.invoke({...})` で実行。テンプレートに変数を流し込むだけで使い回せる
- コード:
  ```python
  from langchain_core.prompts import ChatPromptTemplate
  from langchain_core.output_parsers import StrOutputParser
  from langchain_openai import ChatOpenAI

  template = ChatPromptTemplate.from_messages([
      ("system", "{lang_from}から{lang_to}への翻訳を行います"),
      ("user", "「{text}」を翻訳してください")
  ])
  chain = template | ChatOpenAI(model="gpt-4") | StrOutputParser()
  chain.invoke({"lang_to":"英語","lang_from":"日本語","text":"今日はいい天気ですね"})
  ```
- 投稿アイデア:
  - 型: 昼進捗型 / 教育目的
  - 切り口: 「LangChain、難しそうで触れてなかった。実は 3 行で動く。`prompt | llm | parser`、これだけ」

### 副業所得の計算式の具体数字 — 「売上25万 − 経費8万 = 17万」
- ソース: https://note.com/suiri_mimosa6756/n/ne668594ae495 (AI副業の確定申告解説 note)
- 公開日: 2026 年 (note 著者投稿)
- 要点:
  - 「副業25万売れた = 申告必要」は誤解。所得=売上−経費なので経費8万なら所得17万→所得税申告は不要 (住民税は必要)
  - 経費を取り切ると申告ラインに乗らないケースが普通にある
  - 「会社にバレる」恐怖の大半は申告ルールの理解不足から来てる
- 投稿アイデア:
  - 型: 昼の進捗型 / 教育目的
  - 切り口: 「副業25万売っても所得税申告いらないケースがある。経費の引き算次第」
  - 数字を出して「えっそうなの」を取りに行く
